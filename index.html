الأساسياتBasics

كلمات تتكرّر في كل حديث مع المطوّرين. كل تطبيق تعرفه فيه واجهة تراها، وخلفية تعمل وراءها، وقاعدة بيانات تحفظ، وخادم يجمع ذلك كله، وفريق يدير الكود بأداة اسمها Git.

Words that come up in every conversation with developers: what you see, what runs behind it, where data lives, and how the team manages code.

من واقع الشركات: From real companies: Uber و Git

حين تطلب سيارة من Uber تلمس الواجهة، وتبحث الخلفية عن أقرب سائق، وتحفظ قاعدة البيانات الرحلة. وأداة Git التي تدير بها الفرق كودها كتبها لينوس تورفالدس سنة 2005 لإدارة كود لينكس، واليوم يستعملها أكثر من تسعين في المئة من المطوّرين.

When you order an Uber you touch the interface, the backend finds the nearest driver, and the database stores the trip. Git, the tool teams use to manage code, was written by Linus Torvalds in 2005 for the Linux kernel; today over 90% of developers use it.

الكود (الشيفرة)

Code · Source code

أوامر مكتوبة بلغة برمجة تقول للحاسوب ماذا يفعل خطوة بخطوة. كوصفة الطبخ: مقادير بترتيب محدّد، ولو سقط منها سطر تغيّر الطبق.

مثال سطر يقول: إن كان المبلغ أكبر من الرصيد فارفض الدفع.

Instructions written in a programming language that tell the computer what to do, step by step.

Example A line saying: if the amount exceeds the balance, decline the payment.

لغة البرمجة

Programming language

اللغة التي يكتب بها المطوّر الكود، ولكل لغة مجال تبرع فيه: JavaScript للمتصفح، وPython للبيانات والذكاء الاصطناعي، وJava وC# للأنظمة الكبيرة، وSwift وKotlin للجوال.

مثال موقع متجر يُكتب غالبًا بـJavaScript، وتحليل مبيعاته بـPython.

The language developers write code in; each is strong somewhere: JavaScript for browsers, Python for data and AI (Artificial Intelligence), Java and C# for large systems, Swift and Kotlin for mobile.

Example An online store is usually built with JavaScript, its sales analysis with Python.

قاعدة الكود

Codebase

كل كود المشروع الواحد مجموعًا بملفاته ومجلداته. إن كان الكود وصفة، فقاعدة الكود دفتر وصفات المطعم كاملًا.

مثال «قاعدة الكود كبيرة وقديمة» تعني أن أي تعديل يحتاج حذرًا ووقتًا.

All the source code of one project, with its files and folders.

Example "The codebase is big and old" means every change needs care and time.

الواجهة الأمامية

Frontend

كل ما يراه المستخدم ويلمسه: الشاشات والأزرار والنماذج. هي صالة المطعم بطاولاتها وقائمة طعامها.

مثال صفحة الدفع في تطبيق توصيل الطعام بحقولها وأزرارها.

Everything the user sees and touches: screens, buttons and forms.

Example The checkout screen of a food delivery app.

الخلفية

Backend

ما يعمل خلف الشاشة: يستقبل الطلب، ويتحقّق من الصلاحية، ويحفظ البيانات، ويرسل الإشعار. هي مطبخ المطعم، لا يراه الزبون وعليه يقوم كل شيء.

مثال حين تضغط «اطلب» تحسب الخلفية السعر وتخصم المبلغ وتبلغ المطعم.

The part behind the screen: it receives requests, checks permissions, stores data and sends notifications.

Example When you tap "Order", the backend prices it, charges you and notifies the restaurant.

قاعدة البيانات

Database

مخزن منظّم للمعلومات في جداول، يكتب فيه البرنامج ويقرأ منه بسرعة ودقة. كخزانة أرشيف لكل ملف فيها درج معروف.

مثال جدول العملاء وجدول الطلبات في أي متجر إلكتروني.

An organized store of information, usually in tables, built for fast and reliable reading and writing.

Example The customers table and the orders table of any online store.

الخادم

Server

حاسوب يعمل ليلًا ونهارًا ليردّ على طلبات المستخدمين عبر الإنترنت. كالمطبخ المركزي الذي يخدم كل الفروع.

مثال حين تفتح موقعًا يطلب متصفحك الصفحة من خادمه فيردّ بها.

A computer that runs day and night to answer users' requests over the internet.

Example When you open a website, your browser asks its server for the page.

الاستضافة والنطاق

Hosting · Domain

الاستضافة مكان الخادم الذي يسكن فيه موقعك، والنطاق عنوانه الذي يكتبه الناس مثل example.com. الاستضافة الشقّة، والنطاق العنوان على بابها.

مثال تشتري النطاق من شركة تسجيل، وتستأجر الاستضافة من شركة أخرى، ثم تربطهما.

Hosting is where your site's server lives; the domain is the address people type, like example.com.

Example You buy the domain from a registrar, rent hosting elsewhere, then link them.

الموقع والتطبيق

Website · Web app · Mobile app

الموقع صفحات تُقرأ، وتطبيق الويب برنامج يعمل في المتصفح (مثل Gmail)، وتطبيق الجوال يُنزَّل من متجر التطبيقات. والتطبيق الأصلي (Native) يُكتب لكل نظام وحده، والهجين يُكتب مرة لنظامين.

مثال Gmail في المتصفح تطبيق ويب، وتطبيق Gmail على الآيفون تطبيق جوال.

A website is pages to read; a web app is software in the browser (like Gmail); a mobile app is installed from an app store.

Example Gmail in the browser is a web app; Gmail on the iPhone is a mobile app.

الواجهة وتجربة المستخدم

UI (User Interface) · UX (User Experience)

الواجهة (UI: User Interface) شكل الشاشة: ألوانها وخطوطها وأزرارها. وتجربة المستخدم (UX: User Experience) ما يمرّ به وهو يستعملها: هل وصل إلى غايته بسهولة؟ الواجهة ديكور المحل، والتجربة سهولة أن تجد البضاعة وتدفع وتخرج.

مثال زرّ جميل اللون مسألة واجهة، وأن يجده المستخدم دون أن يسأل أحدًا مسألة تجربة.

UI (User Interface) is how the screen looks; UX (User Experience) is what using it feels like and whether people reach their goal easily.

Example A well-colored button is UI; finding it without asking anyone is UX.

الخلل

Bug

خطأ في الكود يجعل البرنامج يتصرّف على غير ما أُريد له. واشتهر الاسم بعثّة حقيقية علقت سنة 1947 في حاسوب Harvard Mark II، وما زالت ملصقة في سجلّه.

مثال مسبار ناسا المريخي (Mars Climate Orbiter) ضاع سنة 1999 لأن برنامجًا حسب بالباوند وآخر بالنيوتن.

A mistake in code that makes software behave differently from what was intended.

Example NASA's Mars Climate Orbiter was lost in 1999 because one program used pounds and another newtons.

تتبّع الخلل

Debugging

البحث عن سبب الخلل وإصلاحه: إعادة إنتاجه، ثم تضييق مكانه، ثم علاجه، ثم التأكد أنه لم يكسر غيره. كطبيب يشخّص قبل أن يكتب الدواء.

مثال «لا يظهر الخلل إلا عند العملاء في السعودية» يقود المطوّر إلى إعدادات المنطقة الزمنية.

Finding a bug's cause and fixing it: reproduce it, narrow it down, fix it, check nothing else broke.

Example "It only happens for customers in Saudi Arabia" leads the developer to time-zone settings.

الميزة

Feature

قدرة يستعملها المستخدم وينتفع بها، مثل البحث أو التصدير أو الإشعار. وكل ميزة جديدة تعني عملًا ووقتًا واختبارًا جديدًا.

مثال ميزة «تتبّع الشحنة على الخريطة» في تطبيقات التوصيل.

A capability users can use, such as search, export or notifications.

Example The "track your order on a map" feature in delivery apps.

المتطلبات

Requirements

وصف مكتوب لما يجب أن يفعله النظام: ماذا يرى المستخدم، وماذا يحدث عند كل ضغطة، وما القواعد. وكل غموض فيها يُدفع ثمنه أضعافًا في الكود.

مثال «يرسل النظام فاتورة إلى بريد العميل بعد الدفع خلال دقيقة».

A written description of what the system must do: what users see, what each click does, which rules apply.

Example "The system emails the customer an invoice within one minute of payment."

جت وجت هب

Git · GitHub

Git أداة تحفظ تاريخ كل تعديل في الكود وتسمح لفريق كامل بالعمل معًا. وGitHub موقع يستضيف مستودعات Git ويضيف المراجعة والنقاش، واشترته مايكروسوفت سنة 2018، ومثله GitLab.

مثال المطوّر يحفظ عمله بـGit على جهازه، ويرفعه إلى GitHub ليراه الفريق.

Git records every change to code and lets a whole team work together. GitHub hosts Git repositories and adds review and discussion; Microsoft bought it in 2018. GitLab is similar.

Example A developer saves work with Git locally and pushes it to GitHub for the team.

المستودع

Repository · repo

مجلد المشروع مع تاريخه كاملًا: كل تعديل، ومن أجراه، ومتى. وقد يكون خاصًا لا يراه إلا الفريق، أو عامًا يراه الجميع.

مثال مستودع لينكس على GitHub عام، ومستودع تطبيق البنك خاص.

A project folder with its full history: every change, who made it and when. It can be private or public.

Example The Linux repository on GitHub is public; a bank app's repository is private.

الإيداع (كوميت)

Commit

لقطة محفوظة للمشروع في لحظة، معها جملة تصف ما تغيّر ورقم يميّزها. فإن خرب شيء رجعتَ إلى لقطة سابقة.

مثال رفعة وصفها «إصلاح حساب الضريبة في الفاتورة».

A saved snapshot of the project at one moment, with a message and a unique id.

Example A commit titled "Fix tax calculation on invoices".

الرفع

Push

دفع الرفعات من جهازك إلى المستودع المشترك على GitHub، فتصير نسخة احتياطية يراها الفريق. والرفع حفظ وليس اعتمادًا.

مثال «ارفع شغلك قبل أن تغادر» حتى لا يضيع إن تعطّل جهازك.

Sending your local commits to the shared repository so they are backed up and visible to the team.

Example "Push your work before you leave" so it is safe if your laptop dies.

السحب

Pull

عكس الرفع: جلب آخر ما رفعه الزملاء من المستودع إلى جهازك لتعمل على أحدث نسخة.

مثال يسحب المطوّر صباحًا ما رفعه زملاؤه أمس، حتى لا يبني على نسخة قديمة.

The opposite of push: bringing teammates' latest changes to your machine.

Example A developer pulls each morning so as not to build on yesterday's copy.

الفرع

Branch

خط عمل جانبي يجرّب فيه المطوّر دون أن يمسّ النسخة الرئيسية، ثم يدمجه أو يرميه. كدفتر مسوّدة بجانب الدفتر الأصلي.

مثال لكل ميزة فرع باسمها، مثل feature/dark-mode.

A side line of work where changes are tried without touching the main version, then merged or discarded.

Example Each feature gets its own branch, such as feature/dark-mode.

الدمج

Merge

نقل عمل الفرع الجانبي إلى الفرع الرئيسي بعد مراجعته، فيصير جزءًا من المنتج.

مثال ينهي المطوّر ميزة البحث في فرعها، ثم يدمجها بعد موافقة المراجِع.

Bringing a side branch's work into the main branch after review.

Example A developer finishes search in its branch and merges it once approved.

التذكرة

Ticket · Issue

بطاقة لكل عمل أو خلل في نظام مثل Jira: عنوانها، ووصفها، ومن يعمل عليها، وحالها. ومن مجموعها يعرف المدير أين وصل الفريق.

مثال «افتح تذكرة» تعني: سجّل الطلب رسميًا ولا تكتفِ برسالة في الدردشة.

A card for each piece of work or bug in a tool like Jira: title, description, owner and status.

Example "Open a ticket" means log the request formally instead of a chat message.

الاختبار

Test · Testing

التحقّق من أن البرنامج يعمل كما يجب، باليد أو بكود يختبر الكود آليًا في ثوانٍ. و«أخضر» تعني نجاح الاختبارات كلها، و«أحمر» فشل واحد منها على الأقل.

مثال قبل كل إصدار تعمل مئات الاختبارات الآلية وحدها.

Checking that software works, by hand or with code that tests code automatically. Green means all pass, red means something failed.

Example Hundreds of automated tests run before every release.

النشر

Deploy · Deployment

وضع نسخة جديدة من الكود على الخادم ليستعملها الناس. والكود على جهاز المطوّر لا يخدم أحدًا حتى ينشره.

مثال «ننشر الساعة 10 ليلًا» لأن الاستعمال أقلّ.

Putting a new version of the code on the server so people can use it.

Example "We deploy at 10 pm" because usage is low then.

الإنتاج (البيئة الحية)

Production · prod

النسخة الحقيقية التي يعمل عليها الناس ببيانات حقيقية، وكل خطأ فيها يراه العملاء. ويختصرها المطوّرون «prod».

مثال «الخلل في prod» أخطر بكثير من «الخلل في بيئة التجربة».

The live version real people use with real data; every mistake here is visible to customers. Developers shorten it to "prod".

Example "The bug is in prod" is far worse than "the bug is in staging".

العرض التجريبي

Demo

تشغيل البرنامج أمام الناس ليروا كيف يعمل، غالبًا ببيانات تجريبية. غرضه أن يفهم الحاضرون ويعلّقوا، وليس أن يعملوا عليه.

مثال عرض نسخة أولى من التطبيق على المستثمرين قبل جولة التمويل.

Running the software in front of people so they see how it works, usually with sample data.

Example Showing an early version of the app to investors before a funding round.

النسخة الاحتياطية

Backup

نسخة من البيانات في مكان آخر ترجع إليها إن ضاع الأصل. والقاعدة الشائعة 3-2-1: ثلاث نسخ، على وسيطين مختلفين، وواحدة خارج المكان. والنسخة التي لم تُجرَّب استعادتها لا يُعتمد عليها.

مثال في 2017 حذف مهندس في GitLab قاعدة بيانات الإنتاج خطأً، وتبيّن أن أكثر طرق النسخ الاحتياطي عندهم معطّلة، فضاعت بيانات نحو ست ساعات.

A copy of data kept elsewhere to restore if the original is lost. Common rule 3-2-1: three copies, two media, one off-site.

Example In 2017 a GitLab engineer deleted the production database by mistake; most backups turned out broken, and about six hours of data were lost.

التحديث والترقية والرقعة

Update · Upgrade · Patch

التحديث تحسين صغير، والترقية انتقال إلى إصدار أكبر، والرقعة (Patch) إصلاح محدّد لخلل أو ثغرة.

مثال تحديث الآيفون الأمني الصغير رقعة، والانتقال إلى iOS جديد ترقية.

An update is a small improvement, an upgrade a move to a bigger version, a patch a targeted fix for a bug or vulnerability.

Example A small iPhone security update is a patch; moving to a new iOS is an upgrade.

لوحة التحكم

Dashboard · Admin panel

شاشة داخلية يرى فيها المدير الأرقام ويدير البيانات: الطلبات، والمستخدمين، والإعدادات. والعميل لا يراها.

مثال لوحة مطعم في تطبيق توصيل يقبل منها الطلبات ويغيّر الأسعار.

An internal screen where admins see numbers and manage data: orders, users, settings.

Example A restaurant's dashboard in a delivery app to accept orders and change prices.

السحابة

Cloud

خوادم وتخزين تستأجرها من شركة كبرى عبر الإنترنت بدل شرائها ووضعها في مكتبك. كالكهرباء من الشبكة بدل مولّد في كل بيت. وأشهرها AWS (Amazon Web Services) من أمازون وAzure من مايكروسوفت وGoogle Cloud.

مثال صورك في iCloud محفوظة على خوادم آبل وليس على جهازك وحده.

Servers and storage rented over the internet instead of bought and kept in your office. AWS (Amazon Web Services), Azure and Google Cloud lead.

Example Your iCloud photos live on Apple's servers, not only on your phone.

المصدر المفتوح

Open source

برنامج كوده منشور، يقرؤه أي أحد ويعدّله ويستعمله وفق رخصته. والرخصة تحدّد ما يجوز تجاريًا، فاقرأها قبل البيع.

مثال نظام Android ومتصفح Firefox ولغة Python كلها مفتوحة المصدر.

Software whose code is public and can be read, changed and used under its license.

Example Android, Firefox and Python are open source.

السكربت

Script

برنامج قصير يؤدّي مهمة محدّدة وحده، وكثيرًا ما يؤتمت عملًا يتكرّر.

مثال سكربت يجمع مبيعات الأمس كل صباح ويرسلها بالبريد.

A short program that performs a specific task by itself, often automating repeated work.

Example A script that gathers yesterday's sales every morning and emails them.

المستوى الثاني · Level 2 · 40 مصطلحًا

المتوسطIntermediate

كلمات إدارة المشروع التقني: كيف ينتقل الكود من جهاز المطوّر إلى يد المستخدم، وكيف تتكلّم الأنظمة بعضها مع بعض، وكيف تُرتَّب البيانات وتُختبر. والرحلة أدناه تربط أكثرها في قصة واحدة.

How code travels from a developer's laptop to users, how systems talk to each other, and how data is organized and tested.

من واقع الشركات: From real companies: GitHub Flow

تعمل GitHub نفسها بطريقة نشرتها باسم GitHub Flow: فرع لكل تعديل، ثم رفعات، ثم طلب دمج، ثم مراجعة ونقاش، ثم دمج ونشر. وهي اليوم الطريقة الأشيع في الفرق الصغيرة والمتوسطة.

GitHub works with a flow it published as GitHub Flow: a branch per change, commits, a pull request, review and discussion, then merge and deploy. It is now the most common workflow in small and mid-size teams.

رحلة سطر كود من جهاز المطوّر إلى يد المستخدم، بالترتيب. وكل كلمة إنجليزية رابط إلى مصطلحها.

The path of a line of code from a developer's laptop to users, in order.

  1. يكتب المطوّر الكود على جهازه، في البيئة المحلية.CodeLocal
  2. يحفظ لقطة بما غيّر، مع جملة تصفه.Commit
  3. يرفع لقطاته إلى المستودع المشترك.PushRepository
  4. يطلب دمج فرعه في النسخة الرئيسية.BranchPull Request
  5. يقرأ زميل الكود ويعلّق عليه.Code Review
  6. تعمل الاختبارات وحدها، فإمّا أخضر وإمّا أحمر.TestsCI
  7. يدخل العمل الفرع الرئيسي.Merge
  8. ينشره الفريق في بيئة التجربة ويعرضه على أصحاب المصلحة.StagingDemoUAT
  9. ينشره للناس، فيصل إليهم فعلًا.DeployProductionShip
  10. يراقبه وهو يعمل، وإن انكسر شيء تراجع أو أصلح على عجل.MonitoringRollback

البيئات

Local · Development · Staging · Production

يعيش المشروع في نسخ متدرّجة: المحلية على جهاز المطوّر (localhost)، والتطوير المشتركة للفريق، والتجربة (Staging) نسخة تطابق الحقيقية، ثم الإنتاج للناس. كالمسرح: بروفة في الغرفة، ثم بروفة عامة على الخشبة، ثم ليلة العرض.

مثال يجرّب الفريق الدفع الإلكتروني في بيئة التجربة ببطاقات وهمية قبل أن يلمس أموالًا حقيقية.

A project lives in staged copies: local (localhost), shared development, staging that mirrors the real one, then production.

Example The team tests payments in staging with fake cards before touching real money.

إدارة الإصدارات

Versioning · SemVer

ترقيم كل نسخة برقم يقول ما الذي تغيّر. والأشهر ثلاثة أرقام مثل 2.4.1: الأول تغيير كبير قد يكسر ما قبله، والثاني ميزة جديدة، والثالث إصلاح صغير. كطبعات الكتاب: طبعة مزيدة، أو تصحيح خطأ مطبعي.

مثال الانتقال من 2.4.1 إلى 3.0.0 إنذار للمطوّرين: اقرؤوا قبل الترقية.

Numbering each version so the number tells what changed. Semantic Versioning uses MAJOR.MINOR.PATCH, like 2.4.1.

Example Going from 2.4.1 to 3.0.0 warns developers: read before upgrading.

الإصدار وسجلّ التغييرات

Release · Changelog

نسخة مكتملة مختبرة تُسلَّم للمستخدمين في موعد، ومعها ملاحظات الإصدار وسجلّ التغييرات يشرحان الجديد.

مثال «ما الجديد» في متجر التطبيقات تحت كل تحديث هو ملاحظات الإصدار.

A complete, tested version delivered at a set time, with release notes and a changelog explaining what is new.

Example The "What's New" text under each app update is the release notes.

الشحن (الإطلاق الفعلي)

Shipping · Ship it

إيصال الميزة إلى المستخدمين الحقيقيين فعلًا، وليس الانتهاء من كتابتها. والكلمة من شحن البضاعة: ما لم تخرج من المستودع إلى العميل فلم تُبَع.

مثال «شحنّا الميزة» تعني أن الناس يستعملونها اليوم.

Actually delivering a feature to real users, not merely finishing the code.

Example "We shipped it" means people are using it today.

طلب الدمج

Pull Request · PR · Merge Request

طلب على GitHub يقول: «هذا ما غيّرتُه، راجعوه قبل دمجه». فيه الفروق سطرًا سطرًا، والنقاش، والموافقة. ويسمّيه GitLab طلب دمج (Merge Request).

مثال قاعدة صحية: لا يدخل كود إلى الفرع الرئيسي إلا بطلب دمج وافق عليه شخص غير كاتبه.

A request saying "here is what I changed, review it before merging", with line-by-line differences and approval. GitLab calls it a Merge Request.

Example Healthy rule: nothing reaches main without a PR (Pull Request) approved by someone other than its author.

مراجعة الكود

Code Review

يقرأ مطوّر كود زميله قبل الدمج ليكشف الخلل ويحسّن الوضوح وينقل المعرفة. كالتدقيق المحاسبي قبل إقفال الشهر.

مثال في Google لا يدخل تعديل إلى الكود الرئيسي قبل أن يراجعه مهندس آخر.

A developer reads a teammate's code before merging to catch mistakes, improve clarity and share knowledge.

Example At Google no change enters the main codebase before another engineer reviews it.

تعارض الدمج

Merge conflict

يحدث حين يعدّل مطوّران السطر نفسه بطريقتين، فلا يعرف Git أيّهما يأخذ، فيطلب من إنسان أن يحكم.

مثال اثنان غيّرا سعر الشحن في الملف نفسه: واحد إلى 15 والآخر إلى 20.

Happens when two developers change the same lines differently, so Git asks a human to decide.

Example Two people changed the shipping fee in the same file: one to 15, the other to 20.

الواجهة البرمجية

API (Application Programming Interface) · Endpoint

باب متّفق عليه يكلّم منه برنامج برنامجًا آخر: يطلب الأول بصيغة محدّدة، ويردّ الثاني بصيغة محدّدة. وكل عنوان فيه يؤدّي عملًا اسمه نقطة الوصول (Endpoint). كالنادل بينك وبين المطبخ: لا تدخل المطبخ، وتطلب من القائمة.

مثال تطبيق الطقس لا يقيس الطقس، ويطلب الأرقام من API (Application Programming Interface) خدمة أرصاد.

An agreed doorway through which one program talks to another; each address in it is an endpoint.

Example A weather app doesn't measure weather; it asks a forecasting service's API (Application Programming Interface).

REST وJSON

REST (Representational State Transfer) · JSON (JavaScript Object Notation) · GraphQL

REST (Representational State Transfer) أشهر أسلوب لتصميم الواجهات البرمجية، وJSON (JavaScript Object Notation) الصيغة النصية التي تُنقل بها البيانات بينها. وGraphQL بديل نشرته فيسبوك سنة 2015 يطلب فيه العميل الحقول التي يحتاجها وحدها.

مثال ردّ بصيغة JSON: {"name": "Ali", "orders": 3}.

REST (Representational State Transfer) is the most common style for designing APIs; JSON (JavaScript Object Notation) is the text format data travels in. GraphQL, open-sourced by Facebook in 2015, lets clients ask for exactly the fields they need.

Example A JSON reply: {"name": "Ali", "orders": 3}.

الخطّاف الشبكي

Webhook

إشعار ترسله خدمة إلى نظامك لحظة وقوع حدث، بدل أن يسألها نظامك كل دقيقة. كجرس الباب، بدل أن تفتح الباب كل دقيقة لترى إن جاء أحد.

مثال بوابة الدفع ترسل خطّافًا إلى متجرك لحظة نجاح الدفع، فتتحوّل الطلبية إلى «مدفوعة».

A message a service sends to your system the moment something happens, instead of your system asking repeatedly.

Example The payment gateway calls your store's webhook the moment a payment succeeds.

الإطار البرمجي

Framework

هيكل جاهز يبني عليه المطوّر بدل أن يبدأ من الصفر، وفيه الدخول والصلاحيات والاتصال بقاعدة البيانات مرتّبة سلفًا. وأشهرها React للواجهات، وLaravel وDjango وRuby on Rails للخلفية.

مثال Shopify مبني على Ruby on Rails منذ بدايته.

A ready-made structure developers build on instead of starting from scratch. Popular ones: React for interfaces; Laravel, Django and Ruby on Rails for backends.

Example Shopify has been built on Ruby on Rails since the start.

المكتبة والاعتمادية

Library · Package · Dependency

قطعة كود جاهزة كتبها غيرك تضيفها إلى مشروعك لعمل محدّد، ويسمّى كل ما يعتمد عليه مشروعك اعتماديات. فالإطار هو البيت، والمكتبة جهاز تركّبه فيه.

مثال مكتبة جاهزة لرسم المخطّطات بدل كتابة الرسم من الصفر.

Ready-made code by others that you add for a specific job; everything your project relies on is a dependency.

Example A charting library instead of drawing charts from scratch.

حزمة تطوير البرمجيات

SDK (Software Development Kit)

صندوق أدوات تعطيه شركة للمطوّرين ليبنوا على منصتها بسهولة: مكتبات وأمثلة ووثائق.

مثال حزمة Stripe تتيح لمتجرك قبول البطاقات ببضعة أسطر.

A toolbox a company gives developers to build on its platform easily: libraries, samples and docs.

Example Stripe's SDK (Software Development Kit) lets a store accept cards in a few lines.

الدخول والصلاحيات

Authentication · Authorization · SSO (Single Sign-On) · 2FA (Two-Factor Authentication)

سؤالان مختلفان: من أنت؟ وهذا التحقّق من الهوية. وماذا يحقّ لك؟ وهذه الصلاحية. والدخول الموحّد (SSO: Single Sign-On) حساب واحد لأنظمة كثيرة، والتحقّق بخطوتين (2FA: Two-Factor Authentication) رمز ثانٍ بعد كلمة المرور.

مثال زرّ «الدخول بحساب Google» دخول موحّد، ورمز يصل إلى جوالك تحقّق بخطوتين.

Two questions: who are you (authentication) and what may you do (authorization). SSO (Single Sign-On) is one login for many systems; 2FA (Two-Factor Authentication) adds a second code.

Example "Sign in with Google" is SSO; a code sent to your phone is 2FA.

بيانات البذر

Seed data · Seeding

بيانات أولية يزرعها المطوّر في قاعدة بيانات جديدة لتعمل من أول يوم، مثل قائمة الدول والعملات، أو بيانات تجريبية يختبر بها. كالبضاعة التي تُرصّ على رفوف محلّ جديد قبل افتتاحه.

مثال بعد تثبيت نظام جديد تجد فيه حساب المدير والأدوار الأساسية جاهزة، وهذه بيانات بذر.

Initial data planted in a new database so it works from day one, such as countries and currencies, or sample data for testing.

Example A freshly installed system already has an admin account and basic roles: that is seed data.

ملف البذر

Seeder

السكربت الذي يزرع بيانات البذر بأمر واحد. فالبذرة هي البيانات، والباذر هو الأداة التي تضعها. وفي أطر مثل Laravel مجلد خاص لهذه الملفات.

مثال ملف بذر يضيف مئة عميل وهمي ليجرّب الفريق شاشة البحث.

The script that plants seed data with one command. Frameworks like Laravel have a dedicated folder for them.

Example A seeder adds 100 fake customers so the team can test the search screen.

الترحيل والمخطّط

Migration · Schema

المخطّط (Schema) شكل قاعدة البيانات: جداولها وأعمدتها. والترحيل ملف مرقّم يغيّر هذا الشكل خطوة واحدة، فتعرف كل نسخة من المشروع شكل قاعدتها بالضبط. كسجلّ تعديلات المبنى: لكل جدار رخصة وتاريخ.

مثال ترحيل يضيف عمود «رقم الجوال» إلى جدول العملاء.

The schema is the database's shape; a migration is a numbered file that changes it one step at a time.

Example A migration adds a "mobile number" column to the customers table.

SQL وNoSQL

SQL (Structured Query Language) · NoSQL (Not Only SQL) · Query

SQL (Structured Query Language) لغة الاستعلام في قواعد البيانات الجدولية مثل PostgreSQL وMySQL، والاستعلام سؤال تطرحه على البيانات. وNoSQL (Not Only SQL) قواعد بلا جداول صارمة مثل MongoDB، أمرن في الشكل. وPostgreSQL أكثر قاعدة استعمالًا في استطلاع Stack Overflow لسنة 2025.

مثال استعلام: «هات كل طلبات أمس التي تجاوزت ألف ريال».

SQL (Structured Query Language) is the query language of table databases like PostgreSQL and MySQL; NoSQL (Not Only SQL) databases like MongoDB have flexible structures. PostgreSQL was the most used database in Stack Overflow's 2025 survey.

Example A query: "all of yesterday's orders above 1,000 riyals".

مسار التنقّل

Breadcrumbs

سطر صغير أعلى الصفحة يبيّن أين أنت وكيف وصلت، وكل كلمة فيه رابط يعيدك خطوة. والاسم من قصة هانسل وغريتل اللذين نثرا فتات الخبز ليعرفا طريق العودة.

مثال الرئيسية › الإلكترونيات › الهواتف › آيفون 16

A small trail at the top of a page showing where you are; each step links back. Named after Hansel and Gretel's trail of crumbs.

Example Home › Electronics › Phones › iPhone 16

الزاحف والكاشط

Crawler · Scraper · Bot

الزاحف برنامج يمرّ على صفحات الإنترنت وحده، فيقرؤها ويتبع روابطها، وأشهره زاحف Google. والكاشط يستخرج معلومة بعينها مثل الأسعار. وكشط مواقع الآخرين تحكمه شروطها والقانون، فاقرأها قبله.

مثال زاحف Google يقرأ صفحات متجرك ليظهرها في نتائج البحث.

A crawler visits pages automatically and follows links, like Googlebot; a scraper extracts specific data such as prices. Scraping others' sites is governed by their terms and the law.

Example Googlebot reads your store's pages so they appear in search results.

الذاكرة المؤقتة

Cache

نسخة قريبة من معلومة يكثر طلبها، يحفظها النظام ليعطيها بسرعة بدل جلبها من مصدرها كل مرة. كالبضاعة الأكثر طلبًا على الكاونتر، وليست في المستودع الخلفي.

مثال «امسح الكاش» تعني: أعد تحميل الصفحة من مصدرها، فأنت ترى نسخة قديمة.

A nearby copy of frequently requested information, kept to serve it faster.

Example "Clear the cache" means reload from the source; you are seeing an old copy.

الكوكيز والجلسة

Cookies · Session

الكوكيز ملفات صغيرة يحفظها الموقع في متصفحك ليتذكّرك، والجلسة فترة دخولك المتّصلة. ولهذا تطلب المواقع موافقتك على الكوكيز في أوروبا ودول كثيرة.

مثال سلّة المشتريات تبقى ممتلئة حين تعود غدًا بفضل الكوكيز.

Cookies are small files a site stores in your browser to remember you; a session is your continuous logged-in period.

Example Your cart is still full tomorrow thanks to cookies.

الحالة الطرفية

Edge case

موقف نادر في أطراف الاستعمال لم يحسب له أحد: حقل فارغ، أو اسم طويل جدًا، أو تاريخ 29 فبراير. وأكثر الأخطاء تختبئ هنا.

مثال ماذا يحدث إن ألغى العميل الطلب في الثانية نفسها التي خرج فيها السائق؟

A rare situation at the edges of normal use: an empty field, a very long name, February 29. Many bugs hide here.

Example What happens if the customer cancels the very second the driver leaves?

الانتكاس

Regression

خلل يظهر في شيء كان يعمل، لأن تعديلًا جديدًا كسره. ولذلك تعاد الاختبارات القديمة كلها مع كل إصدار.

مثال بعد إضافة كوبونات الخصم توقّف حساب الضريبة عن العمل.

A bug in something that used to work, broken by a new change; that is why old tests rerun with every release.

Example After adding discount coupons, the tax calculation stopped working.

أنواع الاختبارات

Unit · Integration · E2E (End-to-End) · Smoke

اختبار الوحدة يفحص قطعة صغيرة وحدها، واختبار التكامل يفحص قطعًا تعمل معًا، والاختبار الشامل (E2E: End-to-End) يقلّد مستخدمًا من أول الطريق إلى آخره، واختبار الدخان فحص سريع أن الأساس يعمل بعد النشر.

مثال اختبار شامل: يفتح متصفحًا آليًا، ويسجّل الدخول، ويشتري منتجًا، ويتحقّق من الفاتورة.

Unit tests check one small piece; integration tests check pieces together; end-to-end tests mimic a user's whole journey; smoke tests quickly confirm the basics after a deploy.

Example An E2E (End-to-End) test opens a robot browser, logs in, buys a product and checks the invoice.

الكود الموروث

Legacy code

كود قديم ما زال يعمل ويعتمد عليه العمل، وكتبه في الغالب من غادروا، وكل تعديل فيه مخيف.

مثال نظام مصرفي قديم مكتوب بلغة COBOL (Common Business-Oriented Language) ما زال يعالج الحوالات كل يوم.

Old code that still runs and the business depends on, usually written by people who have left; every change is scary.

Example Old banking systems written in COBOL (Common Business-Oriented Language) still process transfers every day.

الكود القالبي

Boilerplate

كود متكرّر لا بدّ منه في كل مشروع ولا إبداع فيه، مثل إعدادات البداية. وتُكتب له قوالب جاهزة توفّر الوقت.

مثال قالب جاهز لمشروع جديد فيه الدخول والتصميم الأساسي، فيبدأ الفريق من الميزة نفسها.

Repetitive code every project needs with no creativity in it, such as startup setup; templates save the time.

Example A starter template with login and basic layout so the team starts with the actual feature.

ألفا وبيتا

Alpha · Beta

ألفا نسخة يجرّبها الفريق داخليًا وعيوبها متوقّعة، وبيتا نسخة يجرّبها عدد محدود من المستخدمين الحقيقيين قبل الإطلاق العام.

مثال برنامج TestFlight من آبل يوزّع نسخ بيتا من التطبيقات على مختبِرين قبل نشرها في المتجر.

Alpha is an internal test version with expected flaws; beta is tried by a limited group of real users before general release.

Example Apple's TestFlight distributes beta versions of apps to testers before App Store release.

المدقّق والمنسّق

Linter · Formatter

أداة تقرأ الكود وتنبّه إلى الأخطاء الشائعة والأسلوب المخالف قبل التشغيل، والمنسّق يرتّب شكله وحده. كالمدقّق الإملائي في برنامج الكتابة.

مثال المدقّق ينبّه: «هذا المتغيّر لم يُستعمل قط».

A tool that reads code and flags common mistakes and style issues before running it; a formatter tidies its layout automatically.

Example The linter warns: "this variable is never used."

سطر الأوامر

CLI (Command-Line Interface) · Terminal

نافذة نصّية يكتب فيها المطوّر أوامر بدل الضغط على الأزرار، وهي أسرع لمن يحفظها.

مثال أمر git push يُكتب في الطرفية فيرفع العمل.

A text window where developers type commands instead of clicking buttons; faster once learned.

Example Typing git push in the terminal uploads the work.

محرّر الكود

IDE (Integrated Development Environment) · Code editor

البرنامج الذي يكتب فيه المطوّر الكود، وفيه التلوين والإكمال والتشغيل والتصحيح. وأشهره VS Code الذي يتصدّر استطلاعات Stack Overflow، ومحرّرات بالذكاء مثل Cursor.

مثال يفتح المطوّر المشروع في VS Code ويعدّل ويشغّل من مكان واحد.

The program developers write code in, with highlighting, autocomplete, running and debugging. VS Code leads Stack Overflow's surveys; AI (Artificial Intelligence) editors like Cursor are rising.

Example A developer opens the project in VS Code and edits and runs it in one place.

المهمة المجدولة

Cron job · Scheduled task

عمل يشغّله النظام وحده في وقت محدّد: كل ليلة، أو كل ساعة، أو أول كل شهر. والاسم من أداة cron في أنظمة يونكس.

مثال تقرير المبيعات يُرسل كل يوم الساعة 7 صباحًا دون أن يضغط أحد زرًّا.

Work the system runs by itself on a schedule: nightly, hourly, monthly. Named after the Unix cron tool.

Example The sales report is emailed every day at 7 am without anyone clicking.

التصميم المتجاوب

Responsive design

صفحة تعيد ترتيب نفسها لتناسب الجوال واللوحي والحاسوب، بدل نسخة لكل جهاز.

مثال قائمة الموقع تصير زرًّا بثلاثة خطوط على الجوال.

A page that rearranges itself to fit phone, tablet and desktop instead of a separate version for each.

Example The site menu becomes a three-line button on phones.

إتاحة الوصول

Accessibility · a11y

تصميم يستعمله الجميع، ومنهم ضعاف البصر ومن يعتمد على قارئ الشاشة أو لوحة المفاتيح. ومعياره العالمي WCAG (Web Content Accessibility Guidelines). وa11y (accessibility) اختصار: حرف a ثم 11 حرفًا ثم y.

مثال نصّ بديل لكل صورة يقرؤه قارئ الشاشة للكفيف.

Design everyone can use, including people with low vision or who rely on screen readers or keyboards. The global standard is WCAG (Web Content Accessibility Guidelines).

Example Alt text on every image lets a screen reader describe it.

التدويل والتعريب

i18n (internationalization) · l10n (localization) · RTL (Right-to-Left)

التدويل (i18n: internationalization) بناء البرنامج ليقبل لغات كثيرة، والتعريب (l10n: localization) ترجمته وتكييفه لبلد بعينه: العملة والتاريخ والاتجاه. والعربية تحتاج اتجاه اليمين إلى اليسار (RTL: Right-to-Left).

مثال تطبيق يقلب واجهته كلها حين تختار العربية، ويعرض السعر بالريال.

Internationalization builds software to support many languages; localization adapts it to a country: currency, dates, direction. Arabic needs right-to-left (RTL: Right-to-Left).

Example An app that mirrors its whole layout when you pick Arabic and shows prices in riyals.

تحسين محركات البحث

SEO (Search Engine Optimization)

ترتيب الموقع ومحتواه ليظهر في أعلى نتائج Google: سرعة، وعناوين واضحة، ومحتوى يجيب عن سؤال الباحث.

مثال صفحة منتج عنوانها «ستائر فندقية مقاومة للحريق» تظهر لمن يبحث بهذه الكلمات.

Shaping a site and its content to rank high in Google results: speed, clear titles, content that answers the searcher.

Example A product page titled "fire-resistant hotel curtains" shows up for that search.

اختبار أ/ب والتحليلات

A/B testing · Analytics

التحليلات تقيس ما يفعله المستخدمون، واختبار أ/ب يعرض نسختين على مجموعتين ويقيس أيّهما أنجح. والقرار للرقم وليس للرأي.

مثال جرّبت Google سنة 2009 أكثر من أربعين درجة من الأزرق للروابط لترى أيّها يجلب ضغطات أكثر.

Analytics measures what users do; an A/B test shows two versions to two groups and measures which wins.

Example In 2009 Google tested about 41 shades of blue for links to see which got more clicks.

نظام إدارة المحتوى

CMS (Content Management System)

لوحة تتيح لغير المبرمج نشر الصفحات والمقالات والصور دون كتابة كود. وأشهرها WordPress الذي يشغّل أكثر من 40% من مواقع الإنترنت.

مثال فريق التسويق ينشر عرض رمضان بنفسه من لوحة WordPress.

A panel that lets non-developers publish pages and posts without code. WordPress, the best known, runs over 40% of websites.

Example The marketing team publishes the Ramadan offer from WordPress themselves.

نظام التصميم

Design system

مكتبة موحّدة للألوان والخطوط والأزرار والقواعد، يبني منها كل فريق فتبدو الشاشات كلها من عائلة واحدة.

مثال نظام Material Design من Google، ودليل واجهات آبل.

A shared library of colors, fonts, components and rules every team builds from, so all screens look like one family.

Example Google's Material Design and Apple's Human Interface Guidelines.

المخطّط والنموذج

Wireframe · Mockup · Prototype

المخطّط رسم بالأبيض والأسود يحدّد أماكن العناصر، والنموذج (Mockup) شكل نهائي ثابت، والنموذج الأولي (Prototype) نسخة تُضغط وتُجرَّب. كمخطّط المهندس، ثم صورة الواجهة، ثم المجسّم الذي تمشي فيه.

مثال المصمّم يرسم المخطّط في Figma، ثم يلوّنه، ثم يربط الشاشات لتُجرَّب كالتطبيق.

A wireframe is a black-and-white layout, a mockup a static final look, a prototype a clickable version to try.

Example A designer sketches in Figma, colors it, then links screens so it can be tried like the app.

المستوى الثالث · Level 3 · 36 مصطلحًا

المتقدّمAdvanced

كلمات البنية والتشغيل والأمان: كيف يبقى النظام شغّالًا حين يكبر، وكيف يُنشر بلا خوف، وكيف يُحمى. لا تحتاج أن تبنيها بنفسك، وتحتاج أن تسأل عنها الأسئلة الصحيحة.

Infrastructure, operations and security: how systems stay up as they grow, ship safely and stay protected. You don't build these yourself; you ask the right questions about them.

من واقع الشركات: From real companies: Netflix

أنهت Netflix نقل أنظمتها كلها إلى سحابة AWS في 2016، وقسّمتها مئات الخدمات المصغّرة. ومنذ أكثر من عشر سنوات تشغّل أداة اسمها Chaos Monkey تطفئ خوادمها عمدًا في ساعات العمل، لتتأكد أن الخدمة تصمد إن سقط أي جزء.

Netflix finished moving its systems to AWS in 2016 and split them into hundreds of microservices. For over a decade it has run Chaos Monkey, a tool that deliberately kills servers during work hours to prove the service survives any failure.

التطوير والتشغيل

DevOps

طريقة عمل تجمع من يكتب الكود ومن يشغّله على الخوادم في فريق واحد بأدوات آلية، فيُختبر كل تعديل ويُنشر ويُراقب وحده تقريبًا. وولد الاسم سنة 2009 من مؤتمر DevOpsDays في بلجيكا. كخط إنتاج متّصل، بدل قسم يرمي البضاعة إلى قسم آخر من فوق الجدار.

مثال في 2009 عرض فريق Flickr كيف ينشر أكثر من عشر مرات يوميًا، فصار العرض من علامات الحركة.

A way of working that joins development and operations with automation, so each change is tested, deployed and monitored almost automatically. The name was born at DevOpsDays in Belgium in 2009.

Example In 2009 Flickr's team showed how they deployed over ten times a day, a landmark talk for the movement.

التكامل والتسليم المستمران

CI/CD (Continuous Integration / Continuous Delivery) · Pipeline

التكامل المستمر (CI: Continuous Integration): كل رفعة تُختبر آليًا فور وصولها. والتسليم المستمر (CD: Continuous Delivery / Continuous Deployment): كل ما ينجح يصير جاهزًا للنشر، أو يُنشر وحده. وخط الأنابيب (Pipeline) سلسلة الخطوات الآلية من الرفعة إلى النشر.

مثال ذكرت أمازون سنة 2011 أنها تنشر تعديلًا كل 11.6 ثانية في المتوسط.

Continuous Integration tests every commit automatically; Continuous Delivery or Deployment makes passing changes ready to release, or releases them. The pipeline is the chain of automated steps.

Example In 2011 Amazon said it deployed a change every 11.6 seconds on average.

البنية التحتية ككود

Infrastructure as Code · IaC

وصف الخوادم والشبكات في ملفات كود بدل إعدادها باليد، فتُبنى نسخة مطابقة بأمر واحد وتُراجع كأي كود. وأشهر أدواتها Terraform.

مثال بيئة تجربة كاملة تُبنى في دقائق من الملفات نفسها التي بنت الإنتاج.

Describing servers and networks in code files instead of manual setup, so an identical copy builds with one command. Terraform is the best known.

Example A full staging environment built in minutes from the same files that built production.

نماذج السحابة

IaaS (Infrastructure as a Service) · PaaS (Platform as a Service) · SaaS (Software as a Service)

ثلاث درجات من الاستئجار: البنية (IaaS: Infrastructure as a Service) تستأجر فيها خوادم خامًا، والمنصة (PaaS: Platform as a Service) تستأجر مكانًا جاهزًا تضع فيه كودك، والبرمجيات (SaaS: Software as a Service) تستأجر برنامجًا كاملًا باشتراك. كاستئجار أرض، ثم مبنى مجهّز، ثم فندق تسكن فيه.

مثال خوادم AWS (Amazon Web Services) EC2 (Elastic Compute Cloud) بنية، وHeroku منصة، وGmail وZoom برمجيات كخدمة.

Three levels of renting: raw servers (IaaS: Infrastructure as a Service), a ready platform for your code (PaaS: Platform as a Service), or finished software by subscription (SaaS: Software as a Service).

Example AWS (Amazon Web Services) EC2 (Elastic Compute Cloud) is IaaS, Heroku is PaaS, Gmail and Zoom are SaaS.

الخلفية الجاهزة

BaaS (Backend as a Service) · Supabase · Firebase

خدمة تعطيك الخلفية كلها دون أن تبني خادمًا: قاعدة بيانات، وتسجيل دخول، وتخزين ملفات، وواجهة برمجية تتولّد وحدها. وأشهرها Firebase من Google، وSupabase البديل المفتوح المصدر المبني على PostgreSQL منذ 2020. كمطبخ مركزي تستأجره جاهزًا فتتفرّغ للصالة.

مثال تطبيق حجز مواعيد صغير يأخذ الدخول وقاعدة البيانات جاهزين من Supabase، فيكتب المطوّر الواجهة وحدها تقريبًا.

A hosted backend with no server of your own: database, sign-in, file storage and auto-generated APIs. Firebase (Google) and Supabase, the open-source PostgreSQL-based alternative since 2020, lead.

Example A small booking app takes sign-in and the database ready-made from Supabase and focuses on the interface.

بلا خوادم

Serverless

تكتب الدالة وحدها، وتشغّلها السحابة عند الحاجة وتحاسبك على ثواني التشغيل، دون أن تدير خادمًا. والخوادم موجودة، لكنها ليست همّك. وبدأت مع AWS (Amazon Web Services) Lambda سنة 2014.

مثال دالة تصغّر كل صورة يرفعها المستخدم، وتعمل لحظة الرفع وحدها.

You write only the function; the cloud runs it on demand and bills per second, with no server to manage. Popularized by AWS (Amazon Web Services) Lambda in 2014.

Example A function that resizes each uploaded photo, running only at upload time.

الحاويات

Containers · Docker

علبة تجمع البرنامج مع كل ما يحتاجه ليعمل، فيعمل بالطريقة نفسها على أي جهاز. والاسم من حاوية الشحن: مقاس موحّد تحمله أي سفينة وأي رافعة. وانتشرت مع Docker منذ 2013.

مثال الحاوية علاج جملة «عندي يشتغل»: البيئة نفسها في كل مكان.

A box packaging software with everything it needs so it runs the same anywhere; popularized by Docker since 2013.

Example Containers cure "it works on my machine".

كوبرنيتيس

Kubernetes · K8s

نظام يدير آلاف الحاويات معًا: يشغّلها، ويوزّعها على الخوادم، ويعيد ما يسقط منها، ويزيدها حين يكثر الضغط. أطلقته Google سنة 2014، والاسم يونانيّ معناه «ربّان السفينة».

مثال ليلة الجمعة البيضاء يضاعف كوبرنيتيس حاويات المتجر وحده، ثم يعيدها بعد الزحام.

A system that runs thousands of containers: schedules them across servers, restarts failures and scales under load. Google released it in 2014; the name is Greek for "helmsman".

Example On Black Friday, Kubernetes multiplies the store's containers, then scales them back down.

النظام الواحد والخدمات المصغّرة

Monolith · Microservices

النظام الواحد (Monolith) كل أجزائه في كتلة، أسهل في البداية وأثقل حين يكبر. والخدمات المصغّرة تقسّمه أنظمة صغيرة يكلّم بعضها بعضًا، أمرن عند الكبر وأعقد إدارة. كمطبخ واحد كبير، مقابل مجمّع مطاعم لكل منها مطبخه.

مثال Netflix تعمل بمئات الخدمات المصغّرة، وShopify تعمل بنظام واحد مقسّم من داخله إلى وحدات.

A monolith keeps everything in one block; microservices split it into small services that talk to each other.

Example Netflix runs hundreds of microservices; Shopify runs a modular monolith.

موزّع الأحمال

Load balancer

بوّاب يوزّع الزوّار على عدّة خوادم حتى لا يختنق واحد ويرتاح غيره، ويتجاوز الخادم المعطّل وحده. كموظّف يوجّه الطابور إلى أقصر صندوق دفع.

مثال ألف طلب في الثانية يتوزّع على خمسة خوادم، مئتين لكل واحد.

A gatekeeper spreading visitors across servers so none chokes, skipping any server that fails.

Example A thousand requests a second spread over five servers, two hundred each.

شبكة توصيل المحتوى

CDN (Content Delivery Network)

خوادم موزّعة حول العالم تحفظ نسخًا من الصور والفيديو قريبًا من المستخدم، فتصله أسرع. وأشهرها Cloudflare.

مثال تضع Netflix أجهزتها داخل شركات الإنترنت نفسها، فيأتيك الفيلم من حيّك وليس من أمريكا.

Servers around the world keeping copies of images and video close to users so they load faster. Cloudflare is the best known.

Example Netflix places its own boxes inside internet providers, so films stream from nearby.

نظام أسماء النطاقات

DNS (Domain Name System)

دليل هاتف الإنترنت: يحوّل اسم الموقع الذي تكتبه إلى رقم الخادم الذي يحمله. فإن تعطّل تاه المتصفح ولو كان الخادم سليمًا.

مثال في أكتوبر 2021 غابت فيسبوك وإنستغرام وواتساب نحو ست ساعات، لأن تعديلًا في الشبكة أخفى عناوينها عن الإنترنت.

The internet's phone book, turning the name you type into the server's number.

Example In October 2021 Facebook, Instagram and WhatsApp vanished for about six hours after a network change hid their addresses.

قابلية التوسّع

Scalability · Horizontal · Vertical

قدرة النظام على خدمة مستخدمين وبيانات أكثر دون أن يبطؤ أو يسقط. والتوسّع العمودي خادم أقوى، والأفقي خوادم أكثر. كمطعم يكبّر مطبخه، أو يفتح فروعًا.

مثال لعبة Pokémon GO جاءها في إطلاقها سنة 2016 نحو خمسين ضعف الزوّار المتوقّعين، فتعثّرت أيامًا.

The ability to serve more users and data without slowing or failing. Vertical means a bigger server; horizontal means more servers.

Example Pokémon GO's 2016 launch drew about fifty times the expected traffic and struggled for days.

التوفّر واتفاقية الخدمة

Uptime · SLA (Service Level Agreement) · SLO (Service Level Objective)

التوفّر نسبة الوقت الذي يعمل فيه النظام. واتفاقية مستوى الخدمة (SLA: Service Level Agreement) وعد مكتوب للعميل فيه تعويض، والهدف الداخلي (SLO: Service Level Objective) رقم يلتزم به الفريق.

مثال نسبة 99.9% تسمح بنحو 43 دقيقة توقّف في الشهر، و99.99% بنحو أربع دقائق.

Uptime is the share of time a system works. An SLA (Service Level Agreement) is a written promise to customers with penalties; an SLO (Service Level Objective) is the team's internal target.

Example 99.9% allows about 43 minutes of downtime a month; 99.99% about 4.

المراقبة والرصد

Monitoring · Observability · Logs

المراقبة تنبّه حين يتعطّل شيء، والرصد يتيح فهم السبب من ثلاث مصادر: السجلات (Logs) والمقاييس والتتبّع. كعدّادات لوحة السيارة والصندوق الأسود في الطائرة.

مثال تنبيه في الثالثة فجرًا: «نسبة الأخطاء في صفحة الدفع تجاوزت 5%».

Monitoring alerts when something breaks; observability explains why, from logs, metrics and traces.

Example A 3 am alert: "error rate on checkout exceeded 5%".

الحادثة والمناوبة

Incident · On-call · SEV (Severity level)

الحادثة عطل يمسّ المستخدمين، وتُرتَّب بدرجات خطورة (SEV1 (Severity 1) أخطرها). والمناوبة أن يكون مهندس جاهزًا لأي تنبيه خارج الدوام بالتناوب.

مثال جوال المهندس المناوب يرنّ ليلًا من تطبيق PagerDuty لأن الموقع سقط.

An incident is a failure affecting users, ranked by severity (SEV1 (Severity 1) is worst). On-call means an engineer takes alerts after hours on a rotation.

Example The on-call engineer's phone rings at night via PagerDuty because the site is down.

زمن الاستجابة

Latency · Performance

الوقت بين ضغطتك وردّ النظام، ويُقاس بأجزاء الثانية. وكل تأخير يُشعر به ينقص الشراء والرضا.

مثال صفحة منتج تحتاج أربع ثوانٍ لتظهر يغادرها كثير من الزوّار قبل أن يروها.

The time between your click and the system's answer, measured in milliseconds; noticeable delays cost sales and satisfaction.

Example A product page that takes four seconds loses many visitors before it appears.

طابور الرسائل

Message queue · Event-driven

صندوق بريد بين الأنظمة: يضع واحد الرسالة ويمضي، ويأخذها الآخر حين يفرغ، فلا ينتظر أحد أحدًا. ومن أشهر أدواته Kafka الذي بدأ في LinkedIn.

مثال طلب الشراء يدخل الطابور، فتأخذه المحاسبة والمستودع والإشعارات كلٌّ في وقته.

A mailbox between systems: one drops a message and moves on, another picks it up when free. Kafka, born at LinkedIn, is a popular one.

Example An order enters the queue; accounting, warehouse and notifications each take it in turn.

تعدّد المستأجرين

Multi-tenancy

نظام واحد يخدم شركات كثيرة، وبيانات كل شركة معزولة عن غيرها. كبرج مكاتب: مبنى واحد ومصعد واحد، ولكل شركة مكتبها ومفتاحها.

مثال Salesforce من أوائل من بنوا نظامًا واحدًا يخدم آلاف الشركات بهذه الطريقة.

One system serving many companies while keeping each one's data isolated.

Example Salesforce was an early pioneer of serving thousands of companies from one system.

الدين التقني

Technical debt

اختصارات وحلول مؤقتة تسرّع العمل اليوم، ثم تدفع فوائدها لاحقًا بطئًا وأخطاء. صاغ الاسم وارد كننغهام سنة 1992. وهو كالدَّين المالي: نافع إن خُطّط له، ومُثقِل إن تراكم.

مثال «نسرّع الإطلاق الآن ونعيد الكتابة الشهر القادم» قرض تقني يحتاج موعد سداد مكتوبًا.

Shortcuts that speed up work today and charge interest later as slowness and bugs. Ward Cunningham coined the term in 1992.

Example "Ship fast now, rewrite next month" is a technical loan that needs a written repayment date.

إعادة الهيكلة

Refactoring

تحسين ترتيب الكود ووضوحه دون أن يتغيّر ما يفعله للمستخدم. كإعادة ترتيب المستودع: البضاعة نفسها، والوصول إليها أسرع.

مثال تقسيم ملف من خمسة آلاف سطر إلى وحدات صغيرة واضحة.

Improving the code's structure and clarity without changing what it does for users.

Example Splitting a 5,000-line file into small, clear modules.

التشفير

Encryption · HTTPS (Hypertext Transfer Protocol Secure) · TLS (Transport Layer Security)

تحويل البيانات إلى رموز لا يقرؤها إلا صاحب المفتاح. والقفل بجانب عنوان الموقع يعني اتصالًا مشفّرًا (HTTPS: Hypertext Transfer Protocol Secure). والتشفير من طرف إلى طرف يمنع حتى الشركة من قراءة رسائلك.

مثال واتساب يشفّر الرسائل من طرف إلى طرف منذ 2016.

Turning data into code only the key holder can read. The padlock means an encrypted HTTPS (Hypertext Transfer Protocol Secure) connection; end-to-end encryption keeps even the provider out.

Example WhatsApp has encrypted messages end to end since 2016.

التجزئة

Hashing

تحويل كلمة المرور إلى بصمة لا تُعكس، فيحفظ الموقع البصمة وحدها ويقارن بها. فإن سُرقت القاعدة لم تُكشف كلمات المرور مباشرة.

مثال إن أرسل لك موقع كلمة مرورك القديمة كما هي، فهو لا يجزّئها، وهذا خطر.

Turning a password into a one-way fingerprint that the site stores and compares.

Example If a site can email you your old password as is, it isn't hashing it, which is dangerous.

انعدام الثقة

Zero trust

مبدأ أمني: لا ثقة تلقائية بأحد ولو كان داخل الشبكة، فكل دخول يتحقّق من الهوية والجهاز في كل مرة. بنته Google لموظفيها باسم BeyondCorp.

مثال الموظف في المكتب يُسأل عن هويته كما يُسأل من يعمل من المقهى.

A security principle: trust no one automatically, even inside the network; verify identity and device every time. Google built it for staff as BeyondCorp.

Example An employee in the office is verified exactly like one working from a café.

الثغرة

Vulnerability · CVE (Common Vulnerabilities and Exposures) · Zero-day

الثغرة عيب يفتح بابًا للمهاجم، ولكل ثغرة معروفة رقم عالمي (CVE: Common Vulnerabilities and Exposures). وثغرة اليوم صفر (Zero-day) ثغرة يستغلّها المهاجمون قبل أن يعرفها صاحب البرنامج.

مثال ثغرة Log4Shell في ديسمبر 2021 أصابت مكتبة سجلات منتشرة في ملايين الأنظمة، فاستنفر العالم لإصلاحها.

A flaw that opens a door to attackers; each known one gets a global CVE (Common Vulnerabilities and Exposures) number. A zero-day is exploited before the vendor knows.

Example Log4Shell in December 2021 hit a logging library inside millions of systems worldwide.

اختبار الاختراق ومكافأة الثغرات

Penetration testing · Bug bounty

اختبار الاختراق هجوم بإذن صاحب النظام ليكشف ثغراته قبل المهاجمين. ومكافأة الثغرات برنامج يدفع لمن يبلّغ عن ثغرة بدل أن يبيعها.

مثال تدفع Google وآبل مكافآت للباحثين الذين يبلّغون عن ثغرات في أنظمتهما.

Penetration testing is an authorized attack to find holes before criminals do; bug bounties pay people who report flaws.

Example Google and Apple pay researchers who report vulnerabilities.

الأمان من البداية

DevSecOps · Shift-left

إدخال الأمان في كل خطوة من خط التطوير بدل فحصه في الآخر، ومعناه «التحويل إلى اليسار»: نحو بداية المخطّط الزمني.

مثال فحص آلي يرفض أي رفعة فيها كلمة مرور مكتوبة داخل الكود.

Building security into every step of the pipeline instead of checking at the end ("shift left" means earlier on the timeline).

Example An automatic check rejects any commit with a password written into the code.

الأسرار ومتغيّرات البيئة

Secrets · Environment variables

كلمات المرور ومفاتيح الخدمات تبقى خارج الكود في خزنة محمية، ويقرؤها البرنامج عند التشغيل، فإن انتشر الكود لم ينتشر المفتاح.

مثال في 2016 وجد مخترقون مفاتيح AWS (Amazon Web Services) داخل مستودع كود خاص لشركة Uber، فوصلوا إلى بيانات 57 مليون شخص.

Passwords and API (Application Programming Interface) keys kept outside the code in a protected vault and read at run time.

Example In 2016 attackers found AWS (Amazon Web Services) keys in a private Uber code repository and reached data on 57 million people.

التعافي من الكوارث

Disaster recovery · RPO (Recovery Point Objective) · RTO (Recovery Time Objective)

خطة الرجوع بعد كارثة: كم بيانات يُحتمل ضياعها (RPO: Recovery Point Objective)، وفي كم وقت يعود النظام (RTO: Recovery Time Objective). وتُجرَّب الخطة قبل الحاجة إليها.

مثال هدف «لا نخسر أكثر من ساعة بيانات، ونعود خلال أربع ساعات».

The plan for coming back after a disaster: how much data you can afford to lose (RPO: Recovery Point Objective) and how fast you must recover (RTO: Recovery Time Objective).

Example Target: lose no more than one hour of data, be back within four hours.

النشر التدريجي

Canary · Blue-green deployment

النشر التدريجي (Canary) يفتح الإصدار الجديد لنسبة صغيرة أولًا ثم يوسّعه، والاسم من عصفور الكناري الذي كان ينبّه عمّال المناجم إلى الغاز. والأزرق والأخضر نسختان كاملتان يُحوَّل الزوّار بينهما في لحظة.

مثال في يوليو 2024 أرسلت CrowdStrike تحديثًا معيبًا إلى العملاء كلهم دفعة واحدة، فتعطّل نحو 8.5 مليون جهاز ويندوز، ثم التزمت بالنشر التدريجي.

Canary releases go to a small share first, then widen; blue-green keeps two full copies and switches traffic instantly.

Example In July 2024 CrowdStrike pushed a faulty update to everyone at once, crashing about 8.5 million Windows machines; it then committed to staged rollouts.

مفتاح الميزة

Feature flag

مفتاح داخل البرنامج يُظهر الميزة أو يخفيها دون نشر جديد، فتفتحها لفئة دون أخرى أو تطفئها فورًا إن أخطأت.

مثال في 2012 أعادت شركة Knight Capital استعمال مفتاح قديم فأيقظ كودًا منسيًا، فخسرت 440 مليون دولار في 45 دقيقة.

A switch inside the software that shows or hides a feature without a new deployment.

Example In 2012 Knight Capital reused an old flag that woke forgotten code and lost $440 million in 45 minutes.

تحديد المعدّل

Rate limiting

سقف لعدد الطلبات المسموح بها في دقيقة أو يوم، يحمي النظام من الإغراق ومن الاستغلال.

مثال واجهة برمجية تسمح بمئة طلب في الدقيقة، وتردّ بعدها «انتظر قليلًا».

A cap on requests per minute or day that protects a system from floods and abuse.

Example An API (Application Programming Interface) allows 100 requests a minute, then replies "slow down".

Monorepo

كود الشركة كلها، بمشاريعها جميعًا، في مستودع واحد بدل مستودع لكل مشروع.

مثال تحفظ Google معظم كودها في مستودع واحد ضخم بلغ مليارَي سطر سنة 2016.

All of a company's projects in one repository instead of one per project.

Example Google keeps most of its code in one giant repository, about two billion lines in 2016.

مستودع البيانات

Data warehouse · ETL (Extract, Transform, Load)

قاعدة تجمع بيانات الأنظمة كلها للتحليل وليس للتشغيل. والاستخراج والتحويل والتحميل (ETL: Extract, Transform, Load) هو نقلها إليها منظّفة كل ليلة.

مثال مبيعات المتجر ومصاريف المحاسبة وحملات التسويق في مكان واحد لتقرير الإدارة.

A database collecting all systems' data for analysis rather than operations; ETL (Extract, Transform, Load) moves it there cleaned, usually nightly.

Example Store sales, accounting costs and marketing campaigns in one place for the management report.

حماية البيانات الشخصية

Data privacy · GDPR (General Data Protection Regulation) · PDPL (Personal Data Protection Law) · KVKK (Kişisel Verilerin Korunması Kanunu)

قوانين تحدّد كيف تجمع بيانات الناس وتحفظها وتحذفها: GDPR (General Data Protection Regulation) في أوروبا منذ 2018، ونظام حماية البيانات الشخصية السعودي (PDPL: Personal Data Protection Law) النافذ منذ سبتمبر 2023، وقانون KVKK (Kişisel Verilerin Korunması Kanunu) التركي منذ 2016.

مثال عميل يطلب حذف بياناته، فيلزمك القانون أن تعرف أين حُفظت كلها.

Laws on how personal data is collected, stored and deleted: GDPR (General Data Protection Regulation) in Europe since 2018, Saudi PDPL (Personal Data Protection Law) in force since September 2023, Turkey's KVKK (Kişisel Verilerin Korunması Kanunu) since 2016.

Example A customer asks you to delete their data; the law expects you to know everywhere it lives.

التراجع والإصلاح العاجل

Rollback · Hotfix

إن كسر إصدار جديد شيئًا في الإنتاج فأمامك طريقان: التراجع فورًا إلى النسخة السابقة، أو إصلاح صغير عاجل يُنشر خارج موعده.

مثال تعطّل زرّ الدفع بعد نشر الصباح: يتراجع الفريق إلى نسخة الأمس في دقائق، ثم يصلح بهدوء.

When a release breaks production: roll back to the previous version immediately, or ship a small urgent fix.

Example Checkout breaks after a morning release: roll back to yesterday's version in minutes, then fix calmly.

الذكاء الاصطناعي في البرمجةAI in software

أسرع ما تغيّر في البرمجة منذ 2023: نماذج لغوية تكتب الكود وتشرحه، ووكلاء ينفّذون مهامّ كاملة، وكلمات جديدة ولدت في 2025 وحدها. والوسم «جديد» على ما انتشر في السنتين الأخيرتين.

The fastest change in software since 2023: language models that write and explain code, agents that finish whole tasks, and new words born in 2025 alone. "New" marks terms that spread in the last two years.

من واقع الشركات: From real companies: Stack Overflow وGoogle

في استطلاع Stack Overflow لسنة 2025 قال 84% من المطوّرين إنهم يستعملون أدوات الذكاء الاصطناعي أو ينوون، وقال 46% إنهم لا يثقون بدقّة ما تخرجه. وقالت Google في أكتوبر 2024 إن أكثر من ربع الكود الجديد عندها يولّده الذكاء الاصطناعي ثم يراجعه مهندسوها.

In Stack Overflow's 2025 survey, 84% of developers said they use or plan to use AI tools, while 46% said they don't trust the accuracy of the output. In October 2024 Google said more than a quarter of its new code is generated by AI and then reviewed by engineers.

الذكاء الاصطناعي وتعلّم الآلة

AI (Artificial Intelligence) · Machine learning · Model

تعلّم الآلة أن يتعلّم البرنامج من أمثلة كثيرة بدل أن تُكتب له القواعد واحدة واحدة. والنموذج هو ما يخرج من هذا التعلّم: ملف يجيب ويتنبّأ.

مثال فلتر البريد المزعج تعلّم من ملايين الرسائل المصنّفة، ولم يكتب له أحد قاعدة لكل رسالة.

Machine learning lets software learn from many examples instead of hand-written rules; the model is the trained result that answers and predicts.

Example A spam filter learned from millions of labeled emails; nobody wrote a rule for each one.

النموذج اللغوي الكبير

LLM · Large Language Model

نموذج تدرّب على كمّ هائل من النصوص فصار يفهم اللغة ويكتبها، ومنها الكود. وأشهرها GPT (Generative Pre-trained Transformer) من OpenAI، وClaude من Anthropic، وGemini من Google، وLlama من Meta.

مثال تطلب منه «اكتب دالة تحسب ضريبة القيمة المضافة 15%» فيكتبها ويشرحها.

A model trained on vast amounts of text that understands and writes language, including code: GPT (Generative Pre-trained Transformer), Claude, Gemini, Llama.

Example Ask it to "write a function for 15% VAT (Value-Added Tax)" and it writes and explains it.

الأمر وصياغته

Prompt · Prompt engineering

الأمر هو ما تكتبه للنموذج، وصياغة الأوامر فنّ كتابته بوضوح: الدور، والمهمة، والسياق، وشكل الجواب المطلوب.

مثال «أنت محاسب. لخّص هذا الكشف في جدول بثلاثة أعمدة» أفضل من «لخّص».

A prompt is what you write to the model; prompt engineering is writing it clearly: role, task, context, expected output.

Example "You are an accountant. Summarize this statement in a three-column table" beats "summarize".

الرموز ونافذة السياق

Tokens · Context window

الرمز قطعة نصّ صغيرة يقيس بها النموذج الكلام ويُحسب بها السعر، والكلمة الإنجليزية نحو رمز وثلث، والعربية أكثر. ونافذة السياق مقدار ما يستطيع النموذج قراءته في المرة الواحدة، وبلغت في بعض النماذج مليون رمز.

مثال ملف كبير قد لا يدخل النافذة، فيُقسَّم أو يُلخَّص قبل إرساله.

A token is a small chunk of text that models count and bill by; an English word is about 1.3 tokens, Arabic more. The context window is how much the model can read at once, up to a million tokens in some models.

Example A huge file may not fit, so it's split or summarized first.

الهلوسة

Hallucination

أن يخترع النموذج معلومة بثقة تامّة: مرجعًا غير موجود، أو رقمًا خاطئًا، أو دالة لا وجود لها. ولهذا يُراجع كل ما يخرج منه.

مثال في 2023 غرّمت محكمة أمريكية محاميَين قدّما مذكرة فيها قضايا مختلقة كتبها ChatGPT.

When a model confidently invents facts: fake references, wrong numbers, functions that don't exist.

Example In 2023 a US court fined two lawyers who filed a brief citing cases ChatGPT had invented.

الوكيل الذكي

AI (Artificial Intelligence) agent · Agentic AI (Artificial Intelligence)

نموذج لا يكتفي بالجواب، بل يخطّط وينفّذ خطوات بأدوات حقيقية: يفتح الملفات، ويشغّل الأوامر، ويجرّب، ويصحّح نفسه، حتى يتمّ المهمة.

مثال وكيل يُعطى «أصلح هذا الخلل» فيقرأ الكود، ويعدّل، ويشغّل الاختبارات، ويفتح طلب دمج.

A model that doesn't just answer but plans and acts with real tools: opens files, runs commands, tests and corrects itself until done.

Example Told "fix this bug", an agent reads the code, edits, runs tests and opens a pull request.

مساعد البرمجة

AI (Artificial Intelligence) coding assistant · Copilot

أداة ذكاء داخل محرّر الكود تكمل السطر، وتشرح، وتكتب أجزاء كاملة. وأشهرها GitHub Copilot الذي ظهر سنة 2021، ثم Cursor وClaude Code وغيرها.

مثال يكتب المطوّر اسم الدالة، فيقترح المساعد جسمها كاملًا، ويقبله المطوّر أو يعدّله.

An AI (Artificial Intelligence) tool in the code editor that completes lines, explains and writes whole parts. GitHub Copilot (2021) led, followed by Cursor, Claude Code and others.

Example A developer types a function name and the assistant proposes the whole body.

برمجة الإحساس(جديد)

Vibe coding(new)

بناء البرنامج بالكلام وحده: تصف ما تريد، ويكتب الذكاء الكود، وتجرّب النتيجة دون أن تقرأ الكود. صاغ العبارة أندريه كارباثي في فبراير 2025. سريعة للنماذج والأدوات الشخصية، وخطرة على نظام فيه أموال الناس وبياناتهم.

مثال مدير يبني أداة صغيرة لتوزيع المناوبات في ساعة دون أن يكتب سطرًا.

Building software by talking: describe what you want, AI (Artificial Intelligence) writes the code, you try the result without reading it. Coined by Andrej Karpathy in February 2025. Fine for prototypes, risky for systems holding people's money and data.

Example A manager builds a small shift-scheduling tool in an hour without writing a line.

البرمجة بالوكلاء(جديد)

Agentic coding(new)

تعطي وكيلًا مهمة محدّدة، فيعدّل ويشغّل ويختبر أكثر العمل، ويبقى الإنسان مالك الهدف والمراجعة. وهي الوجه المسؤول من البرمجة بالذكاء.

مثال «أضف تصدير Excel لتقرير المبيعات مع اختباراته»، ثم يراجع المطوّر ما فعله الوكيل قبل الدمج.

Giving an agent a defined task while it does most editing, running and testing; the human owns the goal and the checks.

Example "Add Excel export to the sales report with tests", then the developer reviews before merging.

هندسة السياق(جديد)

Context engineering(new)

تجهيز كل ما يحتاجه النموذج ليعمل بدقّة: الوثائق، والأمثلة، والقواعد، والأدوات، في المكان والترتيب الصحيحين. انتشر المصطلح في صيف 2025 خليفةً لصياغة الأوامر.

مثال ملف تعليمات في المشروع يقرؤه الوكيل في كل جلسة، فيعرف قواعد الفريق دون أن تعيدها.

Preparing everything a model needs to work accurately: docs, examples, rules and tools, in the right place and order. The term spread in mid-2025 as the successor to prompt engineering.

Example An instructions file in the project that the agent reads every session, so team rules never need repeating.

التطوير الموجّه بالمواصفات(جديد)

Spec-driven development(new)

كتابة المواصفات أولًا، وغالبًا بمساعدة الذكاء، ثم بناء الكود منها، فيتّفق الإنسان والوكيل على الهدف قبل أول سطر. انتشر في 2025 مع أدوات مثل Kiro من أمازون وSpec Kit من GitHub.

مثال وثيقة تقول ما الشاشات وما القواعد وما الاختبارات، ثم يبني الوكيل عليها خطوة خطوة.

Writing the specification first, often with AI (Artificial Intelligence), then building from it, so human and agent agree on the goal before any code. Spread in 2025 with tools like Amazon's Kiro and GitHub's Spec Kit.

Example A document listing screens, rules and tests, then the agent builds from it step by step.

التوليد المعزّز بالاسترجاع

RAG · Retrieval-Augmented Generation

قبل أن يجيب النموذج يبحث في وثائقك أنت ويأخذ منها، فيجيب من مصادرك وليس من ذاكرته العامة. ويقلّ بذلك الاختلاق.

مثال مساعد خدمة عملاء يجيب من دليل سياسات الشركة، ويذكر الفقرة التي أخذ منها.

Before answering, the model searches your own documents and answers from them instead of general memory, reducing invention.

Example A support assistant answering from the company policy manual and citing the paragraph.

التضمين وقاعدة المتّجهات

Embeddings · Vector database

التضمين تحويل النصّ إلى أرقام تمثّل معناه، فتتقارب النصوص المتشابهة في المعنى ولو اختلفت كلماتها. وقاعدة المتّجهات تخزّن هذه الأرقام وتبحث فيها.

مثال بحث عن «إرجاع البضاعة» يجد فقرة عنوانها «سياسة الاستبدال».

Embeddings turn text into numbers that capture meaning, so similar ideas sit close even with different words; a vector database stores and searches them.

Example Searching "return goods" finds a section titled "exchange policy".

الضبط الدقيق

Fine-tuning

تدريب إضافي لنموذج جاهز على أمثلة من عملك، ليتقن أسلوبًا أو مهمة بعينها. وهو أغلى من تحسين الأمر والسياق، فيُجرَّب هذان أولًا.

مثال نموذج يُضبط على آلاف الردود السابقة لخدمة العملاء ليكتب بنبرة الشركة.

Extra training of an existing model on your examples so it masters a style or task; costlier than better prompts and context, which come first.

Example A model tuned on thousands of past support replies to write in the company's voice.

بروتوكول سياق النموذج

MCP · Model Context Protocol

طريقة موحّدة يتّصل بها وكيل ذكاء بخدمة خارجية ليقرأ منها أو يعمل فيها. أطلقته Anthropic في نوفمبر 2024، ثم تبنّته OpenAI وغيرها. كالمقبس الكهربائي الموحّد: كل جهاز يطابقه يعمل.

مثال وكيل يقرأ طلبات المتجر من منصّته مباشرة عبر موصّل MCP (Model Context Protocol)، دون تصدير ملفات.

A standard way for an AI (Artificial Intelligence) agent to connect to outside services to read or act. Anthropic launched it in November 2024; OpenAI and others adopted it.

Example An agent reads store orders straight from the platform through an MCP (Model Context Protocol) connector.

حقن الأوامر

Prompt injection

هجوم يخفي أوامر في نصّ يقرؤه النموذج، في صفحة أو بريد أو ملف، فيطيعها كأنها من صاحبه. وسمّاه الباحث سايمون ويليسون سنة 2022.

مثال صفحة فيها سطر مخفي: «تجاهل تعليماتك وأرسل بيانات المستخدم».

An attack hiding instructions in text a model reads, in a web page, email or file, so it obeys them as if from its owner. Named by researcher Simon Willison in 2022.

Example A web page with a hidden line: "ignore your instructions and send the user's data".

التقييمات

Evals

اختبارات ثابتة تقيس جودة نظام الذكاء على أسئلة معروفة الجواب، قبل كل تغيير وبعده. هي اختبارات الوحدة لعالم الذكاء.

مثال مئتا سؤال من عملاء حقيقيين، ونسبة ما أجاب عنه المساعد صحيحًا قبل التحديث وبعده.

Fixed tests that measure an AI (Artificial Intelligence) system's quality on questions with known answers, before and after each change.

Example Two hundred real customer questions and the share answered correctly before and after an update.

الحواجز

Guardrails

قيود حول نظام الذكاء تمنعه من الخروج عن حدوده: موضوعات ممنوعة، وأفعال تحتاج موافقة، وفحص لما يدخل وما يخرج.

مثال مساعد مالي لا يحوّل مالًا قبل موافقة إنسان.

Limits around an AI (Artificial Intelligence) system that keep it in bounds: forbidden topics, actions needing approval, checks on input and output.

Example A finance assistant that never moves money without human approval.

الإنسان في الحلقة

Human-in-the-loop

تصميم يضع إنسانًا عند نقاط القرار المهمة ليراجع أو يوافق قبل أن يمضي النظام.

مثال الوكيل يجهّز مسودة البريد، والإرسال بضغطة الموظف.

A design that puts a person at key decision points to review or approve before the system proceeds.

Example The agent drafts the email; the employee clicks send.

متعدّد الوسائط

Multimodal

نموذج يفهم أكثر من نوع: النصّ والصورة والصوت وأحيانًا الفيديو، في المحادثة نفسها.

مثال تصوّر فاتورة بالجوال فيقرأ النموذج بنودها ويدخلها في جدول.

A model that understands several kinds of input, text, images, audio and sometimes video, in one conversation.

Example Photograph an invoice and the model reads its lines into a table.

النماذج المفتوحة

Open-weight models

نماذج تنشر شركاتها ملفاتها فيشغّلها أي أحد على خوادمه، مثل Llama من Meta وDeepSeek وMistral. تمنحك تحكّمًا وخصوصية، وتحتاج خبرة وأجهزة.

مثال شركة تشغّل نموذجًا مفتوحًا على خوادمها لأن بياناتها لا يجوز أن تخرج.

Models whose files are published so anyone can run them on their own servers, like Meta's Llama, DeepSeek and Mistral.

Example A company runs an open model in-house because its data must not leave.

CTO · Chief Technology Officer

أعلى مسؤول عن التقنية: يختار الاتجاه والأدوات الكبرى، ويوازن بين ما تريده الشركة وما تقدر عليه التقنية. وفي الشركات الناشئة يكتب الكود بنفسه أحيانًا.

مثال «نبني نظامنا أم نشتري جاهزًا؟» قرار بحجم الرئيس التقني.

The top technology executive: sets direction and major tools, balancing business wants with technical reality.

Example "Build our own system or buy one?" is a CTO (Chief Technology Officer)-sized decision.

نائب الرئيس للهندسة

VP (Vice President) of Engineering

يدير منظومة الهندسة كلها: الناس والتوظيف والعمليات ومواعيد التسليم. الرئيس التقني يقول إلى أين، ونائب الرئيس للهندسة يضمن أن الفرق تصل في موعدها. وفي الشركات الصغيرة يجمع شخص واحد الدورين.

مثال في شركة فيها أربعون مطوّرًا يختار الرئيس التقني الإطار، ويوظّف نائب الرئيس ويبني الفرق ويتابع المواعيد.

Runs the engineering organization: people, hiring, processes and delivery dates. Small companies combine it with the CTO (Chief Technology Officer) role.

Example In a 40-developer company the CTO picks the framework; the VP (Vice President) hires, builds teams and tracks dates.

مدير الفريق الهندسي

Engineering Manager · EM

يدير فريقًا من خمسة إلى عشرة مطوّرين تقريبًا: يوظّفهم، ويلقاهم لقاءات ثنائية، ويقيّم أداءهم، ويزيل ما يعطّلهم. همّه الناس والتسليم أكثر من كتابة الكود.

مثال تأخّر مطوّر مرتين؟ مدير الفريق يجلس معه ليعرف السبب: عبء زائد أم مهارة ناقصة.

Manages roughly 5 to 10 developers: hiring, 1:1s, performance and removing blockers. People and delivery over code.

Example A developer missed two deadlines; the EM (Engineering Manager) finds out whether it is overload or a skill gap.

القائد التقني

Tech Lead · TL

أخبر مطوّري الفريق: يقرّر كيف يُبنى الشيء تقنيًا، ويراجع الكود، ويوجّه الأصغر، وما زال يكتب الكود بنفسه، وقد لا يدير أحدًا إداريًا.

مثال القائد التقني يقرّر أن البحث يحتاج محرّكًا خاصًا، ويقسّم العمل على الفريق.

The most experienced developer on a team: decides how things are built, reviews code, guides juniors and still codes.

Example The tech lead decides search needs a dedicated engine and splits the work.

المعماري

Software / Solutions Architect

يصمّم الهيكل الكبير للنظام: أجزاءه، وكيف يكلّم بعضها بعضًا، وأين تُحفظ البيانات. كالمهندس المعماري يرسم المخطّط قبل أن يبدأ المقاول.

مثال يرسم المعماري كيف يتّصل التطبيق بنظام المحاسبة وبوابة الدفع والمستودع.

Designs the big structure: parts, how they talk and where data lives, like an architect before construction.

Example The architect maps how the app connects to accounting, payments and the warehouse.

مستويات الخبرة

Intern · Junior · Mid-level · Senior

المتدرّب يتعلّم، والمبتدئ يحتاج توجيهًا في أكثر المهام، والمتوسط يستقلّ في المهام الواضحة، والخبير يستقلّ في الغامض أيضًا ويصمّم الحلّ ويعلّم غيره. والسنوات تقريبية، والمعيار الحقيقي مقدار الاستقلال.

مثال تعطي المبتدئ «أضف حقل الرقم الضريبي»، وتعطي الخبير «اجعل النظام يخدم أكثر من فرع».

Interns learn; juniors need guidance on most tasks; mid-level developers handle clear tasks alone; seniors handle ambiguity, design solutions and mentor.

Example Give a junior "add a VAT (Value-Added Tax) number field"; give a senior "make the system serve several branches".

مسار الخبرة الفردية

Staff · Principal · Distinguished Engineer · IC (Individual Contributor)

درجات فوق الخبير لمن يتقدّم دون أن يدير الناس: يحلّ أصعب المشكلات ويؤثّر في فرق عدّة. وهذا «السلّم المزدوج»: مسار للإدارة، ومسار للمساهم الفردي (IC: Individual Contributor)، ولكل منهما رتبه وراتبه.

مثال مطوّر ممتاز لا يحبّ الإدارة لا تجعله مديرًا ليترقّى، ورقّه في مسار الخبرة.

Levels above senior for people who grow without managing others: the dual ladder of management and individual contributor tracks.

Example Don't make a great developer a manager to promote them; promote them on the IC (Individual Contributor) track.

مدير المنتج

Product Manager · PM

يقرّر ماذا نبني ولماذا: يسمع العملاء، ويرتّب الأولويات، ويكتب المتطلبات، ويقيس النتيجة. هو صوت العميل داخل الفريق.

مثال مدير المنتج يقرّر أن «الدفع بالتقسيط» أهمّ هذا الربع من «الوضع الليلي»، ويشرح لماذا بالأرقام.

Decides what to build and why: listens to customers, sets priorities, writes requirements, measures results.

Example The PM (Product Manager) decides installment payments matter more this quarter than dark mode, and shows the numbers.

مالك المنتج

Product Owner · PO

دور في سكرم: صاحب قائمة الأعمال وترتيبها، يقبل العمل المنجز أو يردّه. وفي شركات كثيرة يجمع مدير المنتج هذا الدور.

مثال في مراجعة الدورة يقول مالك المنتج: «هذه مقبولة، وهذه تعود لأنها لا تحقّق شرط القبول».

A Scrum role that owns and orders the backlog and accepts or rejects finished work; often the PM (Product Manager).

Example At sprint review the PO (Product Owner) accepts one story and sends another back for missing a criterion.

مدير المشروع

Project Manager · Delivery Manager

يضمن أن يُسلَّم المشروع في موعده وميزانيته: يخطّط المراحل، ويتابع المخاطر، وينسّق بين الناس. مدير المنتج يسأل «ماذا؟»، ومدير المشروع يسأل «متى؟ وبكم؟».

مثال خطة تقول: التصميم أسبوعان، والبناء ستة، والاختبار اثنان، ولكل مرحلة مسؤول باسمه.

Ensures delivery on time and budget: plans phases, tracks risks, coordinates people. PM (Product Manager) asks "what", project manager asks "when and how much".

Example A plan: two weeks design, six build, two testing, each with a named owner.

ميسّر سكرم

Scrum Master · Agile Coach

يحرس طريقة العمل ولا يدير أحدًا: يضبط مواعيد الاجتماعات ومددها، ويزيل العوائق، ويعلّم الفريق سكرم. كحكم المباراة: لا يسجّل الأهداف، ويحفظ قواعد اللعب.

مثال صار الاجتماع اليومي نصف ساعة؟ ميسّر سكرم يعيده إلى ربع ساعة.

Guards the way of working without managing anyone: keeps events on time, removes blockers, coaches Scrum.

Example The daily stand-up grew to 30 minutes; the Scrum Master brings it back to 15.

محلّل الأعمال

Business Analyst · BA

يترجم حاجة العمل إلى متطلبات واضحة يبني عليها المطوّر: الحقول، والقواعد، والحالات الاستثنائية. هو الجسر بين لغة الإدارة ولغة الكود.

مثال يحوّل «نريد بيعًا آجلًا منظّمًا» إلى حقول النموذج، وسقف الحساب، ومن يعتمد، وماذا يحدث عند الرفض.

Translates business needs into clear requirements developers can build: fields, rules and edge cases.

Example Turning "we want organized credit sales" into fields, limits, approvers and rejection rules.

المصمّم

UX (User Experience) · UI (User Interface) · Product Designer · UX (User Experience) Researcher

باحث التجربة يدرس المستخدمين، ومصمّم التجربة يرسم رحلتهم وهيكل الشاشات، ومصمّم الواجهة يعطيها الشكل والألوان، ومصمّم المنتج يجمع ذلك كله.

مثال يجلس الباحث مع خمسة عملاء يطلبون من التطبيق، فيكتشف أن زرّ الدفع مختبئ.

Researchers study users; UX (User Experience) designers map journeys and structure; UI (User Interface) designers give the look; product designers do it all.

Example A researcher watches five customers order and finds the pay button is hidden.

المطوّرون بتخصّصاتهم

Frontend · Backend · Full-stack · Mobile

مطوّر الواجهة يبني ما يظهر في المتصفح، ومطوّر الخلفية يبني الخوادم وقواعد البيانات، والشامل (Full-stack) يعمل في الاثنين، ومطوّر الجوال يبني تطبيقات iOS وAndroid.

مثال في تطبيق توصيل: شاشة الطلب عمل واجهة، وحساب أقرب سائق عمل خلفية.

Frontend builds what appears in the browser, backend builds servers and databases, full-stack does both, mobile builds iOS and Android apps.

Example In a delivery app, the order screen is frontend; finding the nearest driver is backend.

ضمان الجودة

QA (Quality Assurance) Engineer · Tester · SDET (Software Development Engineer in Test)

يبحث عن الخلل قبل أن يجده العميل: يجرّب بيده، ويكتب اختبارات آلية، ويحاول كسر النظام عمدًا. كمفتّش الجودة على خط الإنتاج.

مثال يدخل مختبِر الجودة اسمًا من مئتي حرف ورقمًا سالبًا، ليرى هل يصمد النموذج.

Finds problems before customers do: manual tests, automated tests and deliberate attempts to break things.

Example A tester enters a 200-character name and a negative number to see if the form holds.

مهندسو التشغيل

DevOps · SRE (Site Reliability Engineering) · Platform Engineer

مهندس DevOps يبني خطوط الاختبار والنشر الآلي والخوادم. ومهندس موثوقية المواقع (SRE: Site Reliability Engineering)، وهو دور ولد في Google سنة 2003، يضمن بقاء النظام شغّالًا وسريعًا. ومهندس المنصّة يبني أدوات داخلية تسهّل على بقية المطوّرين عملهم.

مثال فريق المنصّة يجعل إنشاء خدمة جديدة ضغطة زرّ بدل أسبوع من الإعداد.

DevOps engineers build pipelines and infrastructure; SREs, a role born at Google in 2003, keep systems reliable and fast; platform engineers build internal tools for other developers.

Example The platform team turns "new service" from a week of setup into one click.

أدوار البيانات

Data Engineer · Data Analyst · Data Scientist

مهندس البيانات يبني الأنابيب التي تجمعها وتنظّفها، ومحلّل البيانات يحوّلها تقارير ولوحات، وعالم البيانات يبني نماذج تتنبّأ. أنبوب، ثم تقرير، ثم تنبّؤ.

مثال «أي فئة من العملاء تراجعت مشترياتها هذا العام، ولماذا؟» سؤال محلّل بيانات.

Data engineers build pipelines; analysts turn data into reports and dashboards; data scientists build predictive models.

Example "Which customer segment bought less this year, and why?" is an analyst's question.

مهندس الذكاء الاصطناعي(جديد)

ML (Machine Learning) Engineer · AI (Artificial Intelligence) Engineer(new)

يبني ميزات الذكاء داخل المنتج ويشغّلها: يختار النموذج، ويجهّز السياق والبيانات، ويكتب التقييمات، ويراقب الكلفة والجودة. ومن أسرع الوظائف نموًّا منذ 2023.

مثال يضيف مهندس الذكاء إلى التطبيق مساعدًا يجيب العملاء من دليل سياسات الشركة.

Builds and runs AI (Artificial Intelligence) features in products: picks models, prepares context and data, writes evals, watches cost and quality. One of the fastest-growing roles since 2023.

Example An AI engineer adds an assistant that answers customers from the policy manual.

مهندس الأمن

Security Engineer · CISO (Chief Information Security Officer)

يبحث عن الثغرات قبل المهاجمين، ويراجع الصلاحيات وحماية البيانات، ويختبر الاختراق بإذن. ورئيس أمن المعلومات (CISO: Chief Information Security Officer) يقود هذا الملف في الشركة كلها.

مثال مراجعة أمنية قبل الإطلاق تكشف أن صفحة إدارية تُفتح بلا كلمة مرور.

Finds vulnerabilities before attackers, reviews permissions and data protection, runs authorized tests. The CISO (Chief Information Security Officer) leads security company-wide.

Example A pre-launch review finds an admin page that opens without a password.

مستويات الدعم الفني

Support L1 (Level 1) · L2 (Level 2) · L3 (Level 3)

المستوى الأول يستقبل العميل ويحلّ الشائع، والثاني يحلّ ما يحتاج خبرة أعمق، والثالث مطوّرون يصلحون الخلل في الكود نفسه.

مثال «لا أستطيع الدخول» يحلّها الأول، و«الفاتورة تحسب خطأ» تصعد إلى الثالث.

Level 1 handles common issues, level 2 deeper ones, level 3 developers fix the code itself.

Example "I can't log in" is L1 (Level 1); "the invoice calculates wrong" escalates to L3 (Level 3).

أصحاب المصلحة

Stakeholders · End users

كل من يتأثّر بالمشروع أو يؤثّر فيه من خارج فريق التطوير: الإدارة، والمالية، والمستخدمون النهائيون، والعملاء. تستشيرهم في البداية، ويرون العرض في كل مراجعة.

مثال في نظام فواتير جديد: المحاسبون مستخدمون نهائيون، والمدير المالي صاحب مصلحة يعتمد.

Everyone affected by or influencing the project outside the dev team: management, finance, end users, customers.

Example In a new invoicing system, accountants are end users and the CFO (Chief Financial Officer) is a stakeholder who signs off.

نموذج الفرق

Squad · Tribe · Chapter · Guild

تسميات نشرتها Spotify: الفريق الصغير المستقل Squad، ومجموعة الفرق المتقاربة Tribe، وأهل التخصّص الواحد عبر الفرق Chapter، وأهل الاهتمام الواحد Guild. وقلّدتها شركات كثيرة.

مثال فريق «الدفع» وفريق «السلّة» في قبيلة «الشراء»، ومطوّرو الواجهة منهما في فصل واحد.

Names Spotify popularized: small autonomous squads, groups of squads called tribes, chapters for people with the same skill, guilds for shared interests.

Example The "payments" and "cart" squads sit in the "checkout" tribe; their frontend developers share a chapter.

الفريق متعدّد التخصّصات

Cross-functional team

فريق فيه كل ما يحتاجه ليسلّم وحده: مطوّرو واجهة وخلفية، ومصمّم، ومختبِر، ومالك منتج، فلا ينتظر أقسامًا أخرى.

مثال فريق «الطلبات» يصمّم ويبني ويختبر وينشر ميزته دون أن يرسل تذكرة إلى قسم آخر.

A team holding every skill it needs to deliver alone: front and back end, design, testing and product.

Example The "orders" team designs, builds, tests and ships without filing tickets with other departments.

الفريق الداخلي والخارجي

In-house · Freelancer · Agency · Outsourcing

الفريق الداخلي موظفون عندك، والمستقل يعمل بالساعة أو بالمشروع، والوكالة شركة تبني لك المشروع كاملًا، والتعهيد الخارجي (Offshore) فريق في بلد آخر بكلفة أقل. الداخلي يعرف عملك أعمق، والخارجي أسرع بداية وأخفّ التزامًا.

مثال قبل أن تعطي مستقلًا عملًا، أعطه مواصفات واضحة، فهي تختصر عليه أسابيع من الأسئلة.

In-house staff are your employees; freelancers work by hour or project; agencies build whole projects; offshore teams sit in another country at lower cost.

Example Before hiring a freelancer, hand over clear specs; they save weeks of questions.

الإيقاع · Rhythm · 15 مصطلحًا

الاجتماعاتMeetings

لكل اجتماع في فرق البرمجة غرض ومدة ومخرج، والاجتماع بلا مخرج مكتوب وقت ضائع. والأربعة الأولى تدور في كل دورة سكرم، كما في الرسم.

Every engineering meeting has a purpose, a length and an output; a meeting without a written output is lost time.

من واقع الشركات: From real companies: Amazon

منع جيف بيزوس الشرائح في اجتماعات الإدارة العليا في أمازون منذ 2004، وصار كل اجتماع مهمّ يبدأ بقراءة صامتة لمذكّرة من ست صفحات يكتبها صاحب الاقتراح، ثم يبدأ النقاش.

Jeff Bezos banned slide decks from Amazon's senior meetings in 2004; important meetings start with everyone silently reading a six-page memo, then the discussion begins.

تخطيط الدورةPlanning←اليومي، كل يومDaily←مراجعة الدورةReview←الاستعاديRetroثم دورة جديدة ↺

والتنقيح يجري أثناء الدورة استعدادًا للتي بعدها، وبقية الاجتماعات تُعقد عند الحاجة.

Refinement happens during the sprint to prepare the next one; other meetings happen as needed.

اجتماع الانطلاق

Kickoff

أول اجتماع في المشروع: الهدف، والنطاق، والأدوار، والجدول، وما لن نفعله. يخرج منه الجميع بصورة واحدة. (مرة في البداية · ساعة إلى ساعتين · الفريق وأصحاب المصلحة)

مثال انطلاق تطبيق الولاء: ماذا نبني في الأشهر الثلاثة، ومن يملك ماذا، وما خارج النطاق.

The first project meeting: goal, scope, roles, schedule and what we will not do. (Once · 1-2 h · team and stakeholders)

Example Kicking off a loyalty app: what we build in three months, who owns what, what is out of scope.

تخطيط الدورة

Sprint Planning

يختار الفريق من رأس قائمة الأعمال ما يقدر عليه في الدورة، ويكتب هدفها في جملة واحدة. (أول كل دورة · حتى 4 ساعات لدورة الأسبوعين · مالك المنتج والمطوّرون)

مثال هدف الدورة: «يستطيع العميل الدفع بالتقسيط من صفحة السلّة».

The team picks what it can do from the top of the backlog and writes a one-sentence sprint goal. (Sprint start · up to 4 h for two weeks · PO (Product Owner) and developers)

Example Sprint goal: "customers can pay in installments from the cart page".

الاجتماع اليومي

Daily Stand-up · Daily Scrum

ربع ساعة كل يوم وقوفًا ليبقى قصيرًا، وأسئلته الشائعة ثلاثة: ماذا أنجزتُ أمس؟ وماذا سأنجز اليوم؟ وما الذي يعطّلني؟ والنقاش الطويل بعده. (يوميًا · 15 دقيقة · المطوّرون)

مثال «أنهيتُ صفحة الدفع، واليوم أربطها ببوابة الدفع، ويعطّلني مفتاح الاختبار».

Fifteen minutes daily, standing to keep it short: yesterday, today, blockers. Long talks come after. (Daily · 15 min · developers)

Example "Finished the payment page, wiring the gateway today, blocked on the test key."

تنقيح قائمة الأعمال

Backlog Refinement · Grooming

يوضّح الفريق البنود القادمة، ويقسّم الكبير منها، ويقدّر حجمها، لتكون جاهزة للتخطيط. (مرة أو مرتين في الدورة · ساعة · مالك المنتج والمطوّرون)

مثال بند «تقارير المبيعات» كبير، فيقسّمه الفريق: اليومي، ثم الشهري، ثم التصدير.

The team clarifies, splits and estimates upcoming items so they are ready for planning. (Once or twice a sprint · 1 h · PO (Product Owner) and developers)

Example "Sales reports" is too big, so split it: daily, monthly, then export.

مراجعة الدورة

Sprint Review

يعرض الفريق ما أنجزه شغّالًا وليس شرائح، ويسمع ملاحظات أصحاب المصلحة ليعدّل الخطة. وهي العرض التجريبي الرسمي للدورة. (آخر كل دورة · حتى ساعتين · الفريق وأصحاب المصلحة)

مثال يرى المدير المالي الفاتورة الجديدة تعمل، فيطلب إضافة الرقم الضريبي للعميل.

The team shows working software, not slides, and gathers stakeholder feedback to adjust the plan. (Sprint end · up to 2 h · team and stakeholders)

Example The CFO (Chief Financial Officer) sees the new invoice working and asks for the customer's VAT (Value-Added Tax) number.

الاجتماع الاستعادي

Retrospective · Retro

يسأل الفريق عن طريقة عمله وليس عن المنتج: ما الذي نجح؟ وما الذي نغيّره؟ ويخرج بتحسين أو اثنين محدّدين. (آخر كل دورة · حتى ساعة ونصف · الفريق وحده)

مثال «تأخّرنا لأن المتطلبات وصلت ناقصة، فلا يدخل بند الدورة بلا شروط قبول».

The team looks at how it works, not what it built, and leaves with one or two concrete improvements. (Sprint end · up to 1.5 h · team only)

Example "We slipped because requirements arrived incomplete; no item enters a sprint without acceptance criteria."

اللقاء الثنائي

One-on-One · 1:1

لقاء منتظم بين المدير وأحد أفراد فريقه، ووقته للموظف: نموّه، وعوائقه، ورضاه. وليس اجتماع متابعة مهام. (أسبوعيًا أو كل أسبوعين · نصف ساعة · المدير وموظف)

مثال سؤال يفتح اللقاء: «ما أكثر ما أتعبك هذا الأسبوع؟»

A regular meeting between a manager and one report; the time belongs to the employee: growth, blockers, morale. (Weekly or biweekly · 30 min)

Example An opener: "What drained you most this week?"

اجتماع الجميع

All-Hands · Town Hall

اجتماع للشركة كلها: أخبار ونتائج واتجاه، ثم أسئلة مفتوحة للإدارة. (شهريًا أو كل ربع سنة · ساعة · الجميع)

مثال عرض نتائج الربع على كل الموظفين، ثم أسئلتهم.

A company-wide meeting for news, results and direction, then open questions to leadership. (Monthly or quarterly · 1 h · everyone)

Example Presenting quarterly results to all staff, then taking questions.

مراجعة ما بعد الحادثة

Post-mortem · RCA (Root Cause Analysis)

ماذا حدث؟ ولماذا؟ وكيف نمنع تكراره؟ ويسمّى البحث عن الجذر تحليل السبب الجذري (RCA: Root Cause Analysis). ويُعقد بلا لوم للأشخاص، لأن من يخاف اللوم يخفي الخطأ. (بعد كل عطل كبير · ساعة · من شارك فيه)

مثال بثّت GitLab تعافيها من حادثة حذف قاعدة البيانات سنة 2017 مباشرة، ثم نشرت تحليلها كاملًا للعموم.

What happened, why, and how do we prevent a repeat? Finding the deepest cause is root cause analysis. Held blameless, because people who fear blame hide mistakes. (After major incidents · 1 h)

Example GitLab live-streamed its 2017 database recovery and published the full analysis.

مراجعة التصميم

Design Review · RFC (Request for Comments) · Design Doc

يعرض المطوّر خطته التقنية مكتوبةً قبل البناء، ليكشف زملاؤه الخطأ وهو على الورق حيث تصحيحه أرخص. (قبل كل عمل كبير · ساعة · المعماري والقادة التقنيون)

مثال وثيقة من صفحتين: المشكلة، والحلّ المقترح، والبدائل المرفوضة ولماذا.

A developer presents a written technical plan before building, so colleagues catch problems while they are cheap. (Before large work · 1 h)

Example A two-page doc: the problem, the proposed solution, rejected alternatives and why.

اجتماع قرار الإطلاق

Go / No-Go

سؤال واحد: نطلق أم لا؟ والجواب من قائمة شروط: الاختبارات خضراء، والتدريب تمّ، وخطة التراجع جاهزة. (قبل الإطلاق · نصف ساعة · أصحاب القرار)

مثال «اختبار القبول لم يكتمل عند المالية، فالإطلاق الأحد القادم».

One question, launch or not, answered from a checklist: tests green, training done, rollback ready. (Before launch · 30 min)

Example "Finance hasn't finished acceptance testing, so we launch next Sunday."

جلسة اختبار القبول

UAT · User Acceptance Testing

يجرّب المستخدمون الحقيقيون النظام على حالات من عملهم، ويقرّون أنه يصلح. هم يحكمون، وليس المطوّر. (قبل الإطلاق · أيام · مستخدمون حقيقيون)

مثال ثلاثة محاسبين يمرّرون فواتير الشهر الماضي في النظام الجديد ويقارنون النتائج.

Real users try the system on cases from their own work and sign off. They judge, not the developer. (Before launch · days)

Example Three accountants run last month's invoices through the new system and compare.

اجتماع التسليم

Handoff · Handover

نقل عمل من فريق إلى فريق، مثل نقله من التصميم إلى التطوير، أو من التطوير إلى التشغيل، بوثائقه وأسئلته المفتوحة. (عند انتقال العمل · ساعة · الفريقان)

مثال المصمّم يسلّم شاشات Figma للمطوّرين ويشرح الحالات الخاصة.

Passing work between teams, like design to development, with documents and open questions. (When work changes hands · 1 h)

Example The designer hands Figma screens to developers and walks through special cases.

لجنة التوجيه

Steering committee

اجتماع الإدارة العليا لمشروع كبير: يراجع التقدّم والميزانية والمخاطر، ويحسم ما يعجز عنه الفريق. (شهريًا · ساعة · المديرون والراعي)

مثال تقرّر اللجنة تأجيل ميزة لتلحق الميزانية بالموعد.

Senior leadership's meeting for a large project: progress, budget, risks and decisions the team cannot make. (Monthly · 1 h)

Example The committee postpones a feature to keep the budget on schedule.

الهاكاثون

Hackathon

يوم أو يومان يتفرّغ فيهما المطوّرون لبناء أفكار سريعة خارج الخطة، ثم يعرضونها. وكثير من الميزات المعروفة ولد فيه.

مثال زرّ «أعجبني» في فيسبوك خرج من هاكاثون داخلي سنة 2007.

One or two days where developers build quick ideas outside the plan, then demo them; many known features were born this way.

Example Facebook's Like button came out of an internal hackathon in 2007.

التنظيم · Process · 25 مصطلحًا

طرق العملWays of working

الطرق التي تنظّم بها الفرق عملها، وأدواتها الصغيرة: كيف تكتب الطلب، وكيف تقدّر حجمه، وكيف ترتّبه، وكيف تقيس التقدّم. والجدول يقارن الثلاث الأشهر.

How teams organize work and the small tools that go with it: writing requests, sizing, ordering and measuring progress.

من واقع الشركات: From real companies: Toyota وBasecamp

كانبان ولد في مصانع تويوتا في خمسينيات القرن الماضي: بطاقة تطلب القطع حين ينفد الرف، فلا مخزون زائد. وفي البرمجيات تعمل Basecamp بطريقة سمّتها Shape Up: دورات من ستة أسابيع لمشاريع محدّدة الحجم، يليها أسبوعان للتهدئة والإصلاح.

Kanban was born in Toyota factories in the 1950s: a card requests parts when a shelf empties, so no excess stock. In software, Basecamp works with Shape Up: six-week cycles of fixed-size projects followed by a two-week cool-down.

الشلال

Waterfall

مراحل متتابعة لا تبدأ إحداها حتى تنتهي التي قبلها: المتطلبات، ثم التصميم، ثم البناء، ثم الاختبار، ثم التسليم. واضحة حين يكون المطلوب ثابتًا، ومكلفة حين يتغيّر في منتصف الطريق.

مثال تجهيز فندق جديد: التصميم، ثم التوريد، ثم التركيب، ثم الافتتاح، ولا تركيب قبل وصول البضاعة.

Sequential phases, each starting only when the previous ends: requirements, design, build, test, deliver.

Example Fitting out a new hotel: design, procurement, installation, opening.

الرشاقة

Agile

فلسفة تبني على دفعات صغيرة متكرّرة، تعرض كل دفعة على المستخدم، وتعدّل الخطة بما تتعلّمه. وأصلها بيان من أربع قيم كتبه سبعة عشر مطوّرًا في فبراير 2001. كالطبّاخ يتذوّق ويعدّل الملح أثناء الطبخ، وليس بعد أن يصل الطبق إلى الضيف.

مثال تطبيق يُطلق بثلاث ميزات، ثم يضيف كل أسبوعين ما يطلبه المستخدمون فعلًا.

Building in small repeated increments, showing each to users and adapting. Rooted in the four-value Agile Manifesto written by 17 developers in February 2001.

Example An app launches with three features and adds what users actually ask for every two weeks.

سكرم

Scrum

أشهر طريقة لتطبيق الرشاقة: دورات ثابتة لا تزيد على شهر، وثلاثة أدوار (مالك المنتج، وميسّر سكرم، والمطوّرون)، وأربعة اجتماعات في كل دورة. قدّمها كين شوابر وجيف ساذرلاند سنة 1995، والاسم من الرغبي حين يتقدّم الفريق كتلة واحدة.

مثال دورة أسبوعين: تخطيط يوم الأحد، ويومي ربع ساعة، ومراجعة واستعادي يوم الخميس الثاني.

The most popular Agile framework: fixed sprints of a month or less, three accountabilities and four events per sprint. Introduced by Ken Schwaber and Jeff Sutherland in 1995; named after the rugby scrum.

Example A two-week sprint: planning Sunday, daily 15-minute stand-ups, review and retro on the second Thursday.

الدورة (السبرنت)

Sprint · Iteration

مدة ثابتة قصيرة، غالبًا أسبوعان، يلتزم فيها الفريق بهدف واحد ويسلّم في آخرها شيئًا يعمل. والكلمة من سباق العَدْو القصير: جهد مركّز لمسافة معروفة، ثم وقفة وتقييم، ثم سباق جديد.

مثال «الدورة 14: الدفع بالتقسيط»، تبدأ الأحد وتنتهي بعد أسبوعين بعرض شغّال.

A short fixed period, usually two weeks, with one goal and something working at the end.

Example "Sprint 14: installment payments", starting Sunday, ending two weeks later with a working demo.

كانبان

Kanban · WIP (Work In Progress) limit

لوحة أعمدة: «للعمل»، و«قيد العمل»، و«تمّ»، تنتقل عليها البطاقات، مع حدّ أعلى لما يكون قيد العمل في وقت واحد (WIP (Work In Progress) limit). ولا دورات ثابتة فيها، فالعمل يتدفّق.

مثال فريق دعم فني لا يسمح لنفسه بأكثر من ثلاث تذاكر قيد العمل، فيغلق قبل أن يفتح.

A board of columns, To do, In progress, Done, with a cap on work in progress and no fixed sprints.

Example A support team allows itself only three tickets in progress, finishing before starting.

الإنتاج الرشيق

Lean

مبدأ من تويوتا أيضًا: كل ما لا يضيف قيمة للعميل هدر يُزال، من انتظار ونقل ومخزون زائد وإنتاج قبل الطلب. وفي البرمجة: ميزة لا يستعملها أحد هدر.

مثال تقرير يُعدّ كل أسبوع ولا يقرؤه أحد هدر بلغة Lean.

Also from Toyota: anything that adds no value for the customer is waste. In software, a feature nobody uses is waste.

Example A weekly report nobody reads is waste.

إثبات المفهوم

POC · Proof of Concept

تجربة صغيرة سريعة تجيب عن سؤال واحد: هل الفكرة ممكنة تقنيًا؟ قبل أن تنفق على بنائها. وغالبًا تُرمى بعد أن تجيب.

مثال يومان لإثبات أن الذكاء يقرأ الفواتير الممسوحة بدقّة كافية، قبل بناء نظام كامل.

A small fast experiment answering one question, is it technically possible, before investing; usually thrown away afterwards.

Example Two days to prove AI (Artificial Intelligence) can read scanned invoices accurately before building a full system.

قائمة الأعمال

Backlog

قائمة مرتّبة بكل ما قد يُعمل في المنتج: ميزات وإصلاحات وأفكار. في أعلاها الأهمّ والأوضح، وفي أسفلها ما يحتمل الانتظار.

مثال أعلى القائمة: «إصلاح خطأ الضريبة»، وأسفلها: «الوضع الليلي».

An ordered list of everything that might be done, the most important and clearest at the top.

Example Top: "fix the tax bug"; bottom: "dark mode".

الملحمة والقصة والمهمة

Epic · Story · Task

تدرّج في حجم الأعمال: الملحمة (Epic) هدف كبير يمتدّ أسابيع، تنقسم قصصًا تُنجز كل واحدة في دورة، وتنقسم القصة مهامّ صغيرة.

مثال ملحمة «الدفع الإلكتروني»، وقصة «الدفع بمدى»، ومهمة «شاشة إدخال البطاقة».

A size hierarchy: an epic spans weeks, splits into stories that fit a sprint, which split into small tasks.

Example Epic "online payments", story "pay with a debit card", task "card entry screen".

قصة المستخدم

User story

طلب يُكتب من جهة المستخدم في جملة: «بصفتي ...، أريد ...، حتى ...». تذكّر الفريق بمن يخدم ولماذا، قبل أن يسأل كيف.

مثال «بصفتي عميلًا، أريد حفظ بطاقتي، حتى لا أكتبها في كل طلب».

A requirement in one sentence from the user's side: "As a [role], I want [goal], so that [benefit]."

Example "As a customer, I want to save my card so I don't retype it every order."

شروط القبول وتعريف «تمّ»

Acceptance criteria · Definition of Done

شروط القبول خاصة بكل قصة: متى نعدّها منجزة؟ وتعريف «تمّ» قائمة عامة تسري على كل عمل: مختبر، ومراجَع، وموثّق، ومنشور. وبدونهما يقول المطوّر «خلص» ويقول المدير «ما خلص».

مثال شرط قبول: «إن كانت البطاقة منتهية يرفضها النظام ويبيّن السبب».

Acceptance criteria are per story; the Definition of Done applies to all work: tested, reviewed, documented, deployed.

Example "If the card has expired, the system rejects it and explains why."

التقدير

Estimation · Story points · Planning poker

تقدير حجم العمل قبل البدء: بالساعات، أو بنقاط نسبية (Story Points) تقارن البنود ببعضها، أو بمقاسات القمصان S وM وL. وفي «بوكر التخطيط» يكشف كل عضو تقديره في اللحظة نفسها حتى لا يتبع أحد غيره. والتقدير مدى وليس وعدًا.

مثال «بين ثلاثة أسابيع وخمسة» أصدق من «أسبوعين بالضبط».

Sizing work in hours, relative story points or T-shirt sizes; in planning poker everyone reveals at once so nobody anchors on others. An estimate is a range, not a promise.

Example "Three to five weeks" is more honest than "exactly two".

السرعة ومخطّط الاحتراق

Velocity · Burndown chart

السرعة مقدار ما ينجزه الفريق في الدورة عادةً، ومنها تعرف كم دورة يحتاج الباقي. ومخطّط الاحتراق خطّ يهبط كل يوم بما بقي من عمل الدورة، فإن لم يهبط فهناك عائق.

مثال فريق ينجز 30 نقطة في الدورة وأمامه 120 نقطة، فيحتاج أربع دورات تقريبًا.

Velocity is what a team usually finishes per sprint; a burndown chart shows remaining work dropping day by day.

Example A team doing 30 points per sprint with 120 left needs about four sprints.

خارطة الطريق والمحطّات

Roadmap · Milestone · Deadline

خارطة الطريق صورة الأشهر القادمة: ماذا نبني، ولأي هدف، وبأي ترتيب. والمحطّة نقطة يُقاس عندها التقدّم، والموعد النهائي تاريخ لا يتحرّك.

مثال الربع الأول: الدفع، والثاني: الولاء، والثالث: التطبيق على الجوال.

A roadmap pictures the coming months; a milestone is a checkpoint; a deadline is a date that won't move.

Example Q1 payments, Q2 loyalty, Q3 the mobile app.

ترتيب الأولويات

Prioritization · MoSCoW (Must, Should, Could, Won't)

طريقة لترتيب المطلوب في أربع: لا بدّ منه (Must)، وينبغي (Should)، ويمكن (Could)، ولن نفعله الآن (Won't). وتقابلها طرق بالأرقام مثل RICE (Reach, Impact, Confidence, Effort).

مثال «لا بدّ: الدفع. ينبغي: الكوبونات. يمكن: الوضع الليلي. لن نفعله الآن: المحفظة الرقمية».

Sorting requirements into Must, Should, Could and Won't have; numeric methods like RICE (Reach, Impact, Confidence, Effort) do the same.

Example Must: payments. Should: coupons. Could: dark mode. Won't (now): digital wallet.

زحف النطاق

Scope creep

تضخّم المشروع بطلبات صغيرة متتالية تُضاف دون أن يتغيّر الموعد أو الميزانية، حتى ينهار الجدول. وعلاجه سؤال واحد عند كل إضافة: ماذا نحذف مقابلها؟

مثال «وبما أنكم تعملون عليها، أضيفوا تصديرًا إلى Excel» عشر مرات.

A project swelling through small additions while dates and budget stay fixed, until the schedule collapses. Ask "what do we drop in exchange?"

Example "While you're at it, add Excel export", ten times over.

مصفوفة المسؤوليات

RACI (Responsible, Accountable, Consulted, Informed)

جدول يحدّد لكل مهمة من ينفّذ (Responsible)، ومن يُحاسَب ويقرّر (Accountable) وهو شخص واحد، ومن يُستشار (Consulted)، ومن يُبلَّغ (Informed). يمنع جملة «حسبتُك أنت من سيفعلها».

مثال في إطلاق ميزة: المطوّر ينفّذ، ومدير المنتج يقرّر، والدعم الفني يُستشار، والمبيعات تُبلَّغ.

A chart naming, per task, who is Responsible, Accountable (one person), Consulted and Informed.

Example Launching a feature: developer Responsible, PM (Product Manager) Accountable, support Consulted, sales Informed.

البرمجة الثنائية والجماعية

Pair programming · Mob programming

مطوّران على شاشة واحدة، أحدهما يكتب والآخر يراجع لحظة بلحظة، ثم يتبادلان. والجماعية فريق كامل على شاشة واحدة لمشكلة صعبة.

مثال مطوّر خبير يبرمج مع زميل جديد أسبوعه الأول، فينقل إليه طرق الفريق.

Two developers at one screen, one typing and one reviewing live; mob programming puts a whole team on one screen.

Example A senior pairs with a new hire in their first week to pass on the team's habits.

التطوير الموجّه بالاختبار

TDD (Test-Driven Development) · BDD (Behavior-Driven Development)

يكتب المطوّر الاختبار أولًا، ثم الكود الذي ينجح فيه، ثم يحسّنه. والتطوير الموجّه بالسلوك (BDD: Behavior-Driven Development) يكتب الاختبار بلغة يفهمها غير المبرمج.

مثال اختبار يُكتب قبل الكود: «الخصم لا يتجاوز 50% من السعر».

Write the test first, then code that passes it, then improve. BDD (Behavior-Driven Development) writes tests in language non-developers can read.

Example A test written before the code: "discount never exceeds 50% of the price".

تجميد الكود

Code freeze

فترة قصيرة قبل الإطلاق لا يدخل فيها كود جديد إلا إصلاح خطأ، ليستقرّ ما سيُطلق.

مثال متاجر كثيرة تجمّد كودها قبل موسم التخفيضات حتى لا تتعطّل في أعلى أيام البيع.

A short pre-launch period when only bug fixes go in, so the release settles.

Example Many stores freeze code before the sales season so nothing breaks on peak days.

دليل التشغيل

Runbook · Playbook · SOP

خطوات مكتوبة لعمل متكرّر أو لعطل معروف، يتبعها أي شخص فيصل إلى النتيجة نفسها. وهو إجراء التشغيل القياسي (SOP) بلغة فرق التقنية.

مثال «إذا امتلأ القرص: افعل 1، ثم 2، ثم 3، ثم أبلغ القائد التقني».

Written steps for a recurring task or known failure that anyone can follow to the same result; tech teams' SOP.

Example "If the disk fills up: do 1, 2, 3, then notify the tech lead."

صندوق الوقت والبحث القصير

Timebox · Spike

صندوق الوقت مدة ثابتة لا تُمدّد، تقف عندها وتقيّم. والبحث القصير (Spike) مهمة محدودة الوقت غرضها التعلّم وليس التسليم، تجيب عن سؤال تقني قبل التقدير.

مثال «يومان فقط لنعرف هل مكتبة الخرائط هذه تدعم العربية، ثم نقرّر».

A timebox is a fixed duration you stop at and assess; a spike is a time-limited task to learn, not deliver, answering a technical question before estimating.

Example "Two days only to see if this map library supports Arabic, then we decide."

الأهداف والنتائج ومؤشرات الأداء

OKR (Objectives and Key Results) · KPI (Key Performance Indicator)

مؤشر الأداء (KPI: Key Performance Indicator) رقم تراقبه باستمرار، والأهداف والنتائج الرئيسية (OKR: Objectives and Key Results) هدف طموح لربع سنة تقيسه ثلاث نتائج رقمية. جاءت من Intel، ونقلها جون دور إلى Google سنة 1999.

مثال الهدف: «تجربة دفع لا تُنسى»، والنتائج: إنجاز الدفع في أقل من 30 ثانية، ورفع نسبة الإتمام إلى 80%.

A KPI (Key Performance Indicator) is a number you watch continuously; an OKR (Objectives and Key Results) is an ambitious quarterly objective measured by a few key results. Born at Intel, brought to Google by John Doerr in 1999.

Example Objective "effortless checkout"; key results: under 30 seconds, completion rate up to 80%.

مقاييس DORA

DORA (DevOps Research and Assessment) metrics

أربعة أرقام مشهورة لقياس فريق التطوير: كم مرة ينشر، وكم يستغرق التعديل حتى يصل إلى الناس، وكم نسبة النشرات التي تكسر شيئًا، وكم يحتاج ليعود بعد العطل. جاءت من أبحاث DORA (DevOps Research and Assessment) التي ضمّتها Google.

مثال فريق ينشر يوميًا ويعود من الأعطال في أقل من ساعة من نخبة الفرق في تقارير DORA.

Four well-known numbers for delivery performance: deployment frequency, lead time for changes, change failure rate and time to restore. From the DORA (DevOps Research and Assessment) research program, now part of Google.

Example A team deploying daily and recovering in under an hour ranks among DORA's elite performers.

طريقة Shape Up

Shape Up

طريقة نشرتها Basecamp سنة 2019: تُشكَّل الفكرة وتُحدَّد لها شهية من الوقت، ثم يبني فريق صغير خلال ستة أسابيع بلا تمديد، ثم أسبوعان للتهدئة.

مثال «شهيّتنا لهذه الميزة ستة أسابيع، فإن لم تكتمل نعيد تشكيلها ولا نمدّد».

A method Basecamp published in 2019: shape the idea, set an appetite, build with a small team in six weeks without extensions, then two weeks of cool-down.

Example "Our appetite for this is six weeks; if it doesn't fit, we reshape it rather than extend."

الشركة الناشئة

Startup

شركة صغيرة تبحث عن نموذج عمل يتكرّر ويكبر بسرعة كبيرة، وليس عن دخل مستقر فحسب. فالمطعم الناجح مشروع صغير، والتطبيق الذي يريد أن يخدم الملايين بعد خمس سنوات شركة ناشئة.

مثال تطبيق توصيل يبدأ في حيّ واحد، وخطّته أن يغطّي عشر مدن في ثلاث سنوات.

A young company searching for a repeatable business model that can grow very fast, not just a steady income.

Example A delivery app starting in one neighborhood with a plan to cover ten cities in three years.

المؤسّس والشريك المؤسّس

Founder · Co-founder

من يبدأ الشركة ويحمل خطرها الأول. وكثير من المستثمرين يفضّلون فريقًا من مؤسّسَين أو ثلاثة يكمل بعضهم بعضًا: واحد للمنتج والتقنية، وآخر للبيع والتمويل.

مثال مؤسّس يعرف السوق من عشر سنين فيه، وشريك تقني يبني المنتج.

Whoever starts the company and carries its first risk; investors often prefer two or three co-founders with complementary skills.

Example A founder with ten years in the market plus a technical co-founder who builds the product.

التحقّق من الفكرة

Idea validation · Customer discovery

التأكّد أن المشكلة حقيقية وأن الناس سيدفعون لحلّها، قبل بناء أي شيء: مقابلات، وصفحة تجريبية، وطلبات مسبقة.

مثال صفحة تقول «اشترك ليصلك التطبيق أولًا»، فإن سجّل ألف شخص في أسبوع فالفكرة تستحق.

Making sure the problem is real and people will pay to solve it, before building: interviews, landing pages, pre-orders.

Example A page saying "sign up to get early access"; a thousand sign-ups in a week says the idea is worth it.

التمويل الذاتي

Bootstrapping

أن تبني الشركة بمالك وبإيرادها الأول، دون مستثمرين. تنمو أبطأ، وتبقى الشركة كلها لك والقرار قرارك. والكلمة من مثل إنجليزي: أن ترفع نفسك بأربطة حذائك.

مثال Mailchimp بنت نفسها بلا مستثمرين قرابة عشرين سنة، ثم باعها مؤسّساها إلى Intuit بنحو 12 مليار دولار سنة 2021.

Building the company with your own money and early revenue, without investors: slower growth, full ownership and control.

Example Mailchimp grew for about twenty years without investors, then its founders sold it to Intuit for about $12 billion in 2021.

الوضع الخفي

Stealth mode

أن تعمل الشركة في صمت قبل الإعلان عن نفسها، حتى لا تكشف فكرتها للمنافسين قبل أن تجهز.

مثال موقع شركة ليس فيه إلا شعار وجملة «قريبًا».

Working quietly before announcing, so competitors don't see the idea before it's ready.

Example A company website with only a logo and "coming soon".

الشركة الناشئة الرشيقة

Lean Startup · Build-Measure-Learn

منهج نشره إريك ريس في كتابه سنة 2011: ابنِ أصغر نسخة، ثم قِس ما يفعله الناس بها، ثم تعلّم وعدّل، وكرّر الدورة بأسرع ما تستطيع.

مثال بدل سنة من البناء، شهر لنسخة صغيرة وثلاثة أسابيع لقياس الإقبال عليها.

A method Eric Ries popularized in his 2011 book: build the smallest version, measure how people use it, learn and adjust, and repeat fast.

Example Instead of a year of building: a month for a small version, three weeks to measure demand.

المنتج الأدنى القابل للحياة

MVP · Minimum Viable Product

أصغر نسخة تحلّ مشكلة العميل فعلًا، تطلقها لتتعلّم من الاستعمال الحقيقي قبل أن تنفق على الباقي. كمطعم يبدأ بخمسة أطباق متقنة، وليس بقائمة من مئة طبق.

مثال بدأت Airbnb سنة 2007 بموقع بسيط يؤجّر ثلاث فرش هوائية في شقّة مؤسّسيها.

The smallest version that truly solves the customer's problem, launched to learn from real use before investing in the rest.

Example Airbnb began in 2007 with a simple site renting three air mattresses in its founders' apartment.

ملاءمة المنتج للسوق

Product-market fit · PMF

اللحظة التي يطلب فيها السوق منتجك بنفسه: العملاء يعودون، ويوصون غيرهم، ويغضبون إن غاب. وقبلها كل شيء يحتاج دفعًا. وانتشر المصطلح بمقال لمارك أندريسن سنة 2007.

مثال الطلبات تزيد كل أسبوع مع أن ميزانية الإعلان ثابتة.

The point where the market pulls your product: customers return, refer others and complain if it disappears. Popularized by Marc Andreessen in 2007.

Example Orders grow weekly while the ad budget stays flat.

التحوّل

Pivot

تغيير اتجاه الشركة بعد أن تعلّمت أن خطّتها الأولى لا تنجح، مع الإبقاء على ما بنته من فريق ومعرفة.

مثال Slack كانت أداة داخلية لشركة تصنع لعبة إلكترونية، فلما فشلت اللعبة تحوّلت الشركة إلى الأداة.

Changing direction after learning the first plan doesn't work, while keeping the team and knowledge built so far.

Example Slack began as an internal tool at a game company; when the game failed, the company pivoted to the tool.

الزخم

Traction

أرقام تثبت أن الناس يريدون منتجك: مستخدمون، ومبيعات، ونموّ شهري. وهي أول ما يسأل عنه المستثمر.

مثال «نموّ 20% شهريًا منذ ستة أشهر» جملة تفتح أبواب المستثمرين.

Numbers proving people want the product: users, sales, monthly growth; the first thing investors ask about.

Example "20% monthly growth for six months" opens investors' doors.

العرض الاستثماري

Pitch deck · Elevator pitch

شرائح قليلة يعرض فيها المؤسّس المشكلة والحلّ والسوق والفريق والأرقام وما يطلبه من مال. وعرض المصعد شرح الفكرة كلها في ثلاثين ثانية.

مثال عرض من نحو عشر شرائح، آخرها «نطلب مليون دولار مقابل 15%».

A short slide deck covering problem, solution, market, team, numbers and the ask; an elevator pitch is the whole idea in thirty seconds.

Example About ten slides, the last saying "raising $1 million for 15%".

حجم السوق

TAM (Total Addressable Market) · SAM (Serviceable Available Market) · SOM (Serviceable Obtainable Market)

السوق الكلّي (TAM: Total Addressable Market) كل من يمكن أن يشتري في العالم، والسوق المتاح (SAM: Serviceable Available Market) من تصل إليه فعلًا، والحصة الممكنة (SOM: Serviceable Obtainable Market) ما تقدر أن تكسبه في سنواتك الأولى. والمستثمر يحترم الحصة الواقعية أكثر من السوق الضخم.

مثال كل العيادات في العالم، ثم عيادات الخليج، ثم مئتا عيادة تستطيع خدمتها في ثلاث سنوات.

Total addressable market, serviceable market and the share you can realistically win soon.

Example All clinics worldwide, then Gulf clinics, then 200 you can serve in three years.

المسرّعة والحاضنة

Accelerator · Incubator

المسرّعة برنامج قصير، نحو ثلاثة أشهر، يعطي الشركة مالًا قليلًا وتوجيهًا وشبكة علاقات مقابل حصة، وينتهي بيوم عرض أمام المستثمرين. والحاضنة أطول وأهدأ، وتعطي مكانًا ودعمًا. وأشهر المسرّعات Y Combinator منذ 2005.

مثال من خرّيجي Y Combinator شركات Airbnb وStripe وDropbox.

An accelerator is a short program, about three months, giving small money, mentoring and contacts for equity, ending in a demo day. An incubator is longer and slower. Y Combinator, since 2005, is the most famous.

Example Airbnb, Stripe and Dropbox are Y Combinator alumni.

المستثمر الملاك والمقرّبون

Angel investor · Friends and family

المستثمر الملاك فرد ثري يستثمر ماله الخاص في شركات صغيرة جدًا مبكّرًا، وكثيرًا ما يعطي خبرته معها. وجولة الأهل والأصدقاء أول مال من خارج المؤسّس.

مثال مدير تنفيذي سابق يضع مئة ألف دولار في شركة صديقه ويصير مستشارها.

An angel is a wealthy individual investing their own money very early, often with advice; friends and family is the first outside money.

Example A former executive puts $100,000 into a friend's startup and becomes its adviser.

رأس المال الجريء

Venture capital · VC

صناديق تجمع المال من مستثمرين كبار وتضعه في شركات ناشئة عالية الخطر مقابل حصص، وهي تعلم أن أكثرها سيفشل وأن ناجحًا واحدًا كبيرًا يعوّض الباقي.

مثال صندوق يستثمر في عشرين شركة، تفشل منها خمس عشرة، وتحقّق واحدة منها أكثر من الصندوق كله.

Funds pooling money from large investors into high-risk startups for equity, knowing most will fail and one big winner pays for the rest.

Example A fund backs twenty startups; fifteen fail and one returns more than the whole fund.

جولات التمويل

Pre-seed · Seed · Series A · B · C

سلّم المال بحسب نضج الشركة: ما قبل البذرة لإثبات الفكرة، والبذرة للوصول إلى ملاءمة السوق، والسلسلة A لبناء آلة نموّ تتكرّر، ثم B وC للتوسّع في أسواق ومنتجات جديدة. والمبالغ تكبر مع كل جولة، وتختلف كثيرًا بين البلدان.

مثال جولة بذرة تموّل أول فريق ومنتج، والسلسلة A تموّل فريق مبيعات يغطّي ثلاث مدن.

The funding ladder by maturity: pre-seed proves the idea, seed reaches product-market fit, Series A builds a repeatable growth engine, B and C expand. Amounts grow each round and vary by country.

Example A seed round funds the first team and product; Series A funds a sales team covering three cities.

أدوات التمويل المؤجّل

SAFE (Simple Agreement for Future Equity) · Convertible note

مال يدخل الشركة الآن، ويتحوّل إلى أسهم لاحقًا في الجولة القادمة، فلا يحتاج الطرفان أن يتّفقا على تقييم الشركة اليوم. وأداة SAFE (Simple Agreement for Future Equity) صمّمتها Y Combinator سنة 2013 بديلًا أبسط من القرض القابل للتحويل.

مثال مستثمر يضع مئتي ألف اليوم، وتتحوّل إلى أسهم بخصم حين تأتي جولة البذرة.

Money in now that converts into shares at the next round, so nobody has to agree on a valuation today. Y Combinator designed the SAFE (Simple Agreement for Future Equity) in 2013 as a simpler alternative to convertible notes.

Example An investor puts in $200,000 now, converting at a discount when the seed round comes.

التقييم

Valuation · Pre-money · Post-money

كم تساوي الشركة. والتقييم قبل المال (Pre-money) قيمتها قبل الاستثمار الجديد، وبعده (Post-money) قيمتها مضافًا إليها المال الجديد، ومنه تُحسب حصة المستثمر.

مثال تقييم قبل المال 8 ملايين، واستثمار مليونين، فالتقييم بعده 10 ملايين، وحصة المستثمر 20%.

What the company is worth; pre-money is before the new investment, post-money adds it, and the investor's share follows from it.

Example Pre-money $8M plus $2M invested gives $10M post-money: the investor owns 20%.

الحصص والتخفيف

Equity · Dilution

الحصة نسبة ما تملكه من الشركة. ومع كل جولة تُصدر أسهم جديدة للمستثمرين فتصغر نسبة المؤسّسين، وهذا التخفيف. والمهمّ أن يكبر حجم الكعكة أسرع مما تصغر شريحتك.

مثال مؤسّس يملك 100%، ثم 80% بعد البذرة، ثم 64% بعد السلسلة A، وقيمة حصته تضاعفت مرات.

Equity is your ownership share; each round issues new shares so founders' percentage shrinks. What matters is the cake growing faster than your slice shrinks.

Example A founder goes from 100% to 80% after seed and 64% after Series A, while the stake's value multiplies.

جدول الملكية

Cap table

جدول يبيّن من يملك كم من الشركة: المؤسّسون، والمستثمرون، وخطّة أسهم الموظفين، وأثر كل جولة عليهم.

مثال قبل أي جولة يطلب المستثمر جدول الملكية أولًا.

A table showing who owns what: founders, investors, the employee option pool and the effect of each round.

Example Before any round, investors ask for the cap table first.

الاستحقاق التدريجي

Vesting · Cliff

لا يحصل المؤسّس أو الموظف على أسهمه دفعة واحدة، بل على مدى سنوات، والشائع أربع سنوات. وحدّ السنة الأولى (Cliff) يعني أن من يغادر قبل سنة لا يأخذ شيئًا. يحمي الشركة من شريك يغادر مبكّرًا بحصة كاملة.

مثال شريك يغادر بعد ثمانية أشهر، فلا يأخذ من أسهمه شيئًا لأن حدّ السنة لم يكتمل.

Shares are earned over years, commonly four; a one-year cliff means leaving before a year earns nothing. It protects against a partner leaving early with a full stake.

Example A co-founder leaves after eight months and gets no shares because the cliff wasn't reached.

خطة أسهم الموظفين

ESOP (Employee Stock Ownership Plan) · Stock options

حصة تحجزها الشركة لموظفيها يشترون بها أسهمًا بسعر اليوم، فإن كبرت الشركة ربحوا الفرق. وبها تجذب الشركة الناشئة كفاءات لا تقدر على رواتبها.

مثال مهندس يقبل راتبًا أقل مقابل خيار أسهم قد يساوي الكثير بعد خمس سنوات.

A pool of shares reserved for employees to buy at today's price; if the company grows, they gain the difference. It lets startups hire talent they can't afford in salary.

Example An engineer takes a lower salary for options that could be worth a lot in five years.

ورقة الشروط والفحص

Term sheet · Due diligence

ورقة الشروط ملخّص غير ملزم في أكثره لشروط الاستثمار: المبلغ، والتقييم، والحقوق. ثم يأتي الفحص النافي للجهالة، فيراجع المستثمر الحسابات والعقود والكود والقانون قبل أن يدفع.

مثال ورقة من صفحتين، ثم ستة أسابيع يراجع فيها محامو المستثمر كل عقود الشركة.

A term sheet summarizes the investment terms, mostly non-binding: amount, valuation, rights. Due diligence follows: investors review finances, contracts, code and legal matters before wiring money.

Example A two-page term sheet, then six weeks of the investor's lawyers reviewing every contract.

معدّل الحرق والمدرج

Burn rate · Runway

معدّل الحرق ما تصرفه الشركة شهريًا زيادة على دخلها، والمدرج عدد الأشهر الباقية قبل أن ينفد المال. كطائرة على مدرج: إمّا أن تقلع بأرباح أو جولة جديدة، وإمّا أن ينتهي المدرج.

مثال معنا 1.2 مليون، ونحرق مئة ألف شهريًا، فالمدرج اثنا عشر شهرًا.

Burn rate is how much more the company spends than it earns each month; runway is the months left before cash runs out.

Example $1.2M in the bank burning $100k a month means twelve months of runway.

اقتصاديات الوحدة

Unit economics · CAC (Customer Acquisition Cost) · LTV (Lifetime Value)

كم تكسب من العميل الواحد مقابل كم تدفع لتجلبه. كلفة اكتساب العميل (CAC: Customer Acquisition Cost) مقابل قيمته طوال مدّة تعامله معك (LTV: Lifetime Value). والقاعدة الشائعة أن تكون قيمته ثلاثة أضعاف كلفته على الأقل.

مثال تدفع 50 ريالًا إعلانات لتجلب عميلًا يربحك 200 ريال في عمره، فالنسبة أربعة إلى واحد.

What one customer brings versus what it costs to acquire them: CAC (Customer Acquisition Cost) against lifetime value. A common rule is LTV (Lifetime Value) at least three times CAC.

Example Spending 50 riyals on ads for a customer worth 200 over their lifetime: a 4-to-1 ratio.

الإيراد المتكرّر والتسرّب

MRR (Monthly Recurring Revenue) · ARR (Annual Recurring Revenue) · Churn

الإيراد الشهري المتكرّر (MRR: Monthly Recurring Revenue) دخل الاشتراكات كل شهر، والسنوي (ARR: Annual Recurring Revenue) اثنا عشر ضعفه. والتسرّب (Churn) نسبة من يلغون كل شهر، وهو العدوّ الصامت للنموّ.

مثال مئة ألف شهريًا من الاشتراكات تعني إيرادًا سنويًا متكرّرًا بمليون ومئتي ألف.

Monthly recurring revenue from subscriptions; annual is twelve times that. Churn is the share who cancel each month, growth's silent enemy.

Example $100k a month in subscriptions is $1.2M ARR (Annual Recurring Revenue).

هندسة النمو

Growth hacking · Referral · Viral loop

طرق نموّ سريعة رخيصة مبنية في المنتج نفسه بدل الإعلانات الكبيرة: دعوة صديق بمكافأة، ومشاركة تجلب مستخدمًا جديدًا.

مثال أضافت Hotmail سنة 1996 سطرًا في آخر كل رسالة يدعو إلى بريد مجاني، فانتشرت بلا إعلانات تقريبًا.

Fast, cheap growth built into the product instead of big ad budgets: rewarded invites, sharing that brings new users.

Example In 1996 Hotmail added a line at the end of every email inviting people to get free email, and spread with almost no ads.

خطّة الدخول إلى السوق

Go-to-market · GTM

كيف تصل إلى أول العملاء ثم إلى الكثير: من تستهدف، وبأي قناة، وبأي سعر، ومن يبيع.

مثال البدء بعيادات مدينة واحدة عبر فريق مبيعات مباشر، ثم متجر إلكتروني للبقية.

How you reach the first customers and then many: target, channel, price and who sells.

Example Start with clinics in one city through direct sales, then an online store for the rest.

الخندق

Moat

ميزة تحمي الشركة من المنافسين كما يحمي الخندق القلعة: علامة قوية، أو شبكة مستخدمين، أو كلفة انتقال عالية، أو تقنية يصعب نسخها. والتشبيه لوارن بافيت.

مثال كل مستخدم جديد في تطبيق مراسلة يزيد قيمته لغيره، فيصعب على المنافس جذب الناس منه.

An advantage protecting the company like a moat around a castle: brand, network effects, switching costs, hard-to-copy tech. Warren Buffett's image.

Example Every new user of a messaging app makes it more valuable to others, so rivals struggle to pull people away.

التوسّع

Scale-up · Blitzscaling

مرحلة ما بعد ملاءمة السوق: الشركة تكرّر ما نجح في مدن وأسواق جديدة بسرعة. والتوسّع الخاطف (Blitzscaling)، وهو عنوان كتاب لريد هوفمان سنة 2018، يقدّم السرعة على الكفاءة عمدًا للسيطرة على السوق.

مثال الانتقال من مدينة واحدة إلى خمس دول في سنتين.

The stage after product-market fit: repeating what works in new cities and markets fast. Blitzscaling, Reid Hoffman's 2018 book, deliberately puts speed before efficiency.

Example Going from one city to five countries in two years.

اليونيكورن

Unicorn · Decacorn

شركة ناشئة خاصة يبلغ تقييمها مليار دولار، والديكاكورن عشرة مليارات. صاغت الاسم المستثمرة أيلين لي سنة 2013 لأن هذه الشركات كانت نادرة ندرة الحيوان الأسطوري.

مثال كريم توصف بأنها أول يونيكورن تقني في الشرق الأوسط.

A private startup valued at $1 billion; a decacorn at $10 billion. Investor Aileen Lee coined the term in 2013 because such companies were as rare as the mythical animal.

Example Careem is often called the Middle East's first tech unicorn.

الجولة الهابطة والجسرية

Down round · Bridge round

الجولة الهابطة تمويل بتقييم أقل من الجولة السابقة، فيخسر الملّاك من قيمة حصصهم. والجولة الجسرية مال مؤقّت يوصل الشركة إلى جولتها الكبيرة القادمة.

مثال تقييم 50 مليونًا في الجولة الماضية، و30 مليونًا هذه المرة.

A down round raises money at a lower valuation than the last; a bridge round is temporary money to reach the next big round.

Example Valued at $50M last round, $30M this time.

التخارج

Exit · Acquisition · Acqui-hire

اللحظة التي يحوّل فيها المؤسّسون والمستثمرون حصصهم إلى مال: باستحواذ شركة أكبر، أو بطرح عام. واستحواذ المواهب (Acqui-hire) شراء الشركة لأجل فريقها أكثر من منتجها.

مثال استحواذ Uber على كريم بـ3.1 مليار دولار سنة 2020.

When founders and investors turn shares into cash: acquisition by a larger company or a public offering. An acqui-hire buys a company mainly for its team.

Example Uber's $3.1 billion acquisition of Careem in 2020.

الطرح العام والإدراج

IPO (Initial Public Offering) · Listing · Lock-up

أن تبيع الشركة أسهمها للجمهور أول مرة وتُدرج في البورصة، فتصير شركة مساهمة عامة تنشر حساباتها بانتظام. وفترة الحظر (Lock-up) مدّة بعد الطرح يُمنع فيها المؤسّسون والمستثمرون الأوائل من البيع، وأشيعها ستة أشهر.

مثال في السعودية أدرجت جاهز أسهمها في السوق الموازية «نمو» سنة 2022.

Selling shares to the public for the first time and listing on a stock exchange, becoming a public company that reports regularly. The lock-up stops insiders selling for a period after listing, commonly six months.

Example In Saudi Arabia, Jahez listed its shares on the Nomu parallel market in 2022.

الإدراج المباشر والاستحواذ الخاص

Direct listing · SPAC (Special Purpose Acquisition Company)

الإدراج المباشر دخول البورصة دون بيع أسهم جديدة ودون وسطاء الطرح التقليدي، كما فعلت Spotify سنة 2018. وشركة الاستحواذ ذات الغرض الخاص (SPAC: Special Purpose Acquisition Company) شركة مدرجة فارغة تندمج بشركة خاصة فتدخلها البورصة من الباب الجانبي، وانتشرت في 2020 و2021.

مثال Spotify أُدرجت في بورصة نيويورك سنة 2018 دون طرح أسهم جديدة.

A direct listing enters the exchange without issuing new shares or traditional underwriters, as Spotify did in 2018. A SPAC (Special Purpose Acquisition Company) is an empty listed company that merges with a private one, a side door to the market that boomed in 2020-2021.

Example Spotify listed on the New York Stock Exchange in 2018 without issuing new shares.

العامية · Slang · 32 مصطلحًا

عامية المطوّرينDeveloper slang

كلمات لا تجدها في الكتب، وتسمعها كل يوم في الدردشة والاجتماعات ومراجعات الكود. وكلها هنا موسومة «عامية». تفهمها فتفهم نصف ما يقال في قناة الفريق.

Words you won't find in textbooks but will hear daily in chats, meetings and code reviews. Every term here is slang.

من واقع الشركات: From real companies: GitHub وملف المصطلحات

لعامية المبرمجين تاريخ مكتوب: «ملف المصطلحات» (Jargon File) بدأ سنة 1975 في مختبر الذكاء الاصطناعي بجامعة ستانفورد. واليوم في GitHub رمز تعبيري لسنجاب صغير اسمه :shipit: يضعه المراجعون موافقةً على الإطلاق، تحية لعبارة «اشحنها».

Programmer slang has a written history: the Jargon File began in 1975 at Stanford's AI Lab. Today GitHub even has a squirrel emoji, :shipit:, that reviewers post to approve a release.

اشحنها(عامية)

Ship it(slang)

«جاهز، أطلقه للناس». تقال حين يكتمل العمل بما يكفي، ولو لم يكن كاملًا.

مثال «الاختبارات خضراء والمراجعة تمّت. اشحنها».

"It's ready, release it." Said when work is good enough, even if not perfect.

Example "Tests are green and the review is done. Ship it."

برود وديف(عامية)

prod · dev · env · repo · config(slang)

اختصارات يومية: prod للإنتاج، وdev للتطوير أو المطوّر، وenv للبيئة، وrepo للمستودع، وconfig للإعدادات.

مثال «الخلل في prod فقط، وعلى dev كل شيء سليم».

Everyday short forms: production, development or developer, environment, repository, configuration.

Example "It only breaks in prod; on dev everything's fine."

يبدو جيدًا(عامية)

LGTM · Looks Good To Me(slang)

موافقة المراجِع على طلب الدمج في كلمة واحدة. وأحيانًا تقال دون قراءة حقيقية، فاحذر LGTM (Looks Good To Me) السريعة.

مثال تعليق على طلب دمج من ثلاثمئة سطر بعد دقيقة: «LGTM».

A reviewer's approval in one word; sometimes given without real reading.

Example A 300-line PR (Pull Request) approved in one minute: "LGTM (Looks Good To Me)".

قيد العمل(عامية)

WIP · Work in progress(slang)

عمل لم يكتمل بعد، يُعرض للاطّلاع وليس للمراجعة النهائية.

مثال طلب دمج عنوانه «[WIP (Work In Progress)] صفحة الدفع».

Unfinished work, shared for a look rather than final review.

Example A pull request titled "[WIP (Work In Progress)] checkout page".

ملاحظة صغيرة(عامية)

Nit · Nitpick(slang)

ملاحظة شكلية صغيرة في المراجعة لا تمنع الدمج، مثل اسم متغيّر أو مسافة زائدة.

مثال «nit: سمّ المتغيّر total بدل t».

A small cosmetic review comment that doesn't block merging.

Example "nit: name the variable total instead of t."

العائق(عامية)

Blocker · Unblock(slang)

ما يمنعك من التقدّم حتى يُحلّ. وطلب «فكّ العائق» (unblock) نداء للمدير أو لزميل ليتدخّل.

مثال «عائقي: لم يصلني مفتاح الاختبار من بوابة الدفع».

Whatever stops you from moving until it is resolved; "unblock me" is a call for help.

Example "Blocker: I still don't have the payment gateway's test key."

ابعتلي بينغ(عامية)

Ping · Nudge(slang)

رسالة قصيرة لتذكير أحد أو لفت انتباهه. والاسم من أمر شبكي يفحص هل الجهاز الآخر يردّ.

مثال «اعمل لي ping حين تنتهي من المراجعة».

A short message to remind or get someone's attention, named after the network command that checks if a machine answers.

Example "Ping me when you finish the review."

لغة الاجتماعات(عامية)

Sync · Circle back · Take it offline · Deep dive(slang)

«سنك» اجتماع قصير للتنسيق، و«نعود إليها» تأجيل لطيف، و«نأخذها خارج الاجتماع» نقل نقاش جانبي إلى جلسة أصغر، و«غوص عميق» دراسة مفصّلة لموضوع واحد.

مثال «هذا نقاش طويل، نأخذه خارج الاجتماع، ونعمل سنك غدًا».

Meeting talk: a sync is a short alignment call; circle back means revisit later; take it offline means discuss separately; a deep dive is a detailed study.

Example "That's a long one; let's take it offline and sync tomorrow."

اختصارات الدردشة(عامية)

ETA (Estimated Time of Arrival) · EOD (End Of Day) · OOO (Out Of Office) · FYI (For Your Information) · TL;DR (Too Long; Didn't Read) · ASAP (As Soon As Possible)(slang)

ETA (Estimated Time of Arrival) الوقت المتوقّع للانتهاء، وEOD (End Of Day) نهاية يوم العمل، وOOO (Out Of Office) خارج المكتب، وFYI (For Your Information) للعلم، وTL;DR (Too Long; Didn't Read) الخلاصة لمن لا يقرأ الطويل، وASAP (As Soon As Possible) بأسرع ما يمكن.

مثال «ETA للإصلاح؟» «EOD، وأنا OOO غدًا».

Estimated time, end of day, out of office, for your information, the short version, as soon as possible.

Example "ETA (Estimated Time of Arrival) on the fix?" "EOD (End Of Day), and I'm OOO (Out Of Office) tomorrow."

الجدال في التوافه(عامية)

Bikeshedding(slang)

أن يطيل الفريق الجدال في تفصيل صغير يفهمه الجميع، ويمرّ على القرار الكبير سريعًا. والاسم من لجنة تناقش لون موقف الدرّاجات ولا تناقش مخطّط المفاعل.

مثال ساعة على لون زرّ، وخمس دقائق على اختيار قاعدة البيانات.

Spending far too long on trivial details everyone understands while rushing the big decision, after a committee arguing over a bike shed's color.

Example An hour on a button color, five minutes on choosing the database.

حلاقة الياك(عامية)

Yak shaving(slang)

سلسلة مهامّ جانبية لا بدّ منها قبل المهمة الأصلية: تصلح خللًا، فتحتاج تحديث مكتبة، فتحتاج ترقية أداة، وبعد ثلاث ساعات تنسى لماذا بدأت.

مثال «كنت أريد تغيير نصّ زرّ، وانتهى بي اليوم في إعدادات الخادم».

A chain of side tasks you must finish before the real one, until you forget why you started.

Example "I wanted to change a button label and spent the day in server settings."

جحر الأرنب(عامية)

Rabbit hole(slang)

الغرق في تفصيل أو بحث يأخذ وقتًا أكثر مما يستحق ويبعدك عن الهدف.

مثال «لا تدخل جحر الأرنب هذا الآن، سجّله وارجع إلى المهمة».

Sinking into a detail that eats more time than it deserves.

Example "Don't go down that rabbit hole now; log it and get back to the task."

كود السباغيتي(عامية)

Spaghetti code(slang)

كود متشابك بلا ترتيب، كل جزء مربوط بكل جزء، فإن سحبت خيطًا تحرّك الصحن كله.

مثال «لا أستطيع تعديل الخصم دون أن ينكسر الشحن، كله سباغيتي».

Tangled, structureless code where everything touches everything.

Example "I can't change discounts without breaking shipping; it's all spaghetti."

حلّ ترقيعي(عامية)

Hacky · Quick and dirty · Band-aid(slang)

حلّ سريع يعمل الآن ولا يصمد طويلًا، كلصقة جروح على أنبوب يقطر. وقد يكون مقبولًا لليلة واحدة إن سُجّل لإصلاحه.

مثال «هذا حلّ ترقيعي لننقذ الإطلاق، والإصلاح الحقيقي في الدورة القادمة».

A quick fix that works now but won't last; acceptable short-term if logged for a real fix.

Example "This is a band-aid to save the launch; the real fix is next sprint."

تصحيح البطة المطاطية(عامية)

Rubber duck debugging(slang)

أن تشرح مشكلتك بصوت عالٍ لبطة مطاطية على مكتبك، فتجد الحلّ وأنت تشرح. والفكرة من كتاب The Pragmatic Programmer سنة 1999.

مثال يبدأ المطوّر يشرح الخلل لزميله، ويقول في منتصف الجملة: «وجدتُه، شكرًا».

Explaining a problem out loud, even to a rubber duck, until you find the answer yourself. From The Pragmatic Programmer, 1999.

Example A developer starts explaining the bug and stops mid-sentence: "Found it, thanks."

عندي يشتغل(عامية)

Works on my machine(slang)

جملة المطوّر الشهيرة حين يعمل الكود على جهازه ويتعطّل عند غيره، وسببها اختلاف البيئة. والحاويات علاجها.

مثال «عندي يشتغل!» «طيب، نشحن جهازك للعملاء؟».

The famous line when code runs locally but fails elsewhere, usually due to environment differences.

Example "It works on my machine!" "Great, shall we ship your laptop to customers?"

خلل هايزنبرغ(عامية)

Heisenbug(slang)

خلل يختفي أو يتغيّر حين تحاول مراقبته، تيمّنًا بمبدأ الريبة عند هايزنبرغ.

مثال خلل لا يظهر أبدًا حين يشغّل المطوّر أدوات التتبّع.

A bug that disappears or changes when you try to observe it, after Heisenberg's uncertainty principle.

Example A bug that never appears while the debugger is running.

المسار السعيد(عامية)

Happy path(slang)

الطريق الذي يمضي فيه كل شيء كما يجب، بلا أخطاء ولا حالات غريبة. والاختبار الجيّد يتجاوزه إلى غير السعيد.

مثال «جرّبتَ المسار السعيد فقط؟ ماذا لو رُفضت البطاقة؟».

The path where everything goes right; good testing goes beyond it.

Example "You only tested the happy path? What if the card is declined?"

بندقية القدم(عامية)

Footgun(slang)

ميزة أو إعداد يسهّل أن تؤذي نفسك به، كبندقية تطلق على قدمك.

مثال زرّ «احذف الكل» بلا تأكيد بجانب زرّ «حفظ».

A feature that makes it easy to shoot yourself in the foot.

Example A "delete all" button with no confirmation next to "save".

خطأ الإصبع السمين(عامية)

Fat-finger error(slang)

خطأ كتابة بشري صغير بنتيجة كبيرة.

مثال في فبراير 2017 أراد مهندس في AWS (Amazon Web Services) إيقاف عدد قليل من الخوادم، فأخطأ في أمر واحد، فتعطّل جزء كبير من الإنترنت ساعات.

A small human typo with big consequences.

Example In February 2017 an AWS (Amazon Web Services) engineer mistyped one command meant to remove a few servers and knocked out much of the internet for hours.

عامل الحافلة(عامية)

Bus factor(slang)

كم شخصًا يلزم أن يغيبوا فجأة حتى يتوقّف المشروع؟ فإن كان الجواب واحدًا فالخطر كبير.

مثال «عامل الحافلة عندنا واحد: لا أحد غير سامي يفهم نظام الفواتير».

How many people would have to vanish suddenly for the project to stall; one is dangerous.

Example "Our bus factor is one: only Sami understands invoicing."

المعرفة القبلية(عامية)

Tribal knowledge(slang)

معلومات مهمّة في رؤوس الناس وليست مكتوبة، تضيع إن غادروا. وعلاجها التوثيق.

مثال «كيف ننشر؟ اسأل خالد، هو وحده يعرف الترتيب».

Important knowledge living in people's heads, not in documents.

Example "How do we deploy? Ask Khaled, only he knows the order."

إطفاء الحرائق(عامية)

Firefighting(slang)

قضاء اليوم في إصلاح طوارئ متلاحقة بدل العمل المخطّط. وإن صار عادة فالمشكلة في الجذور.

مثال «لم ننجز شيئًا من الدورة، كنّا نطفئ حرائق طوال الأسبوع».

Spending the day on one emergency after another instead of planned work.

Example "We delivered nothing this sprint; we were firefighting all week."

نصف قطر الانفجار(عامية)

Blast radius(slang)

مقدار ما يتأثّر إن فشل شيء: قليل من المستخدمين أم الجميع؟ والنشر التدريجي يصغّره.

مثال «لو فتحنا الميزة لـ5% أولًا، صار نصف قطر الانفجار صغيرًا».

How much is affected if something fails; staged rollouts shrink it.

Example "Release to 5% first and the blast radius stays small."

لا نشر يوم الجمعة(عامية)

Don't deploy on Friday(slang)

قاعدة عرفية في فرق كثيرة: لا تنشر قبل العطلة، فإن انكسر شيء قضى الفريق عطلته في إصلاحه. وفي الخليج تقال عن الخميس.

مثال «الإصلاح جاهز، لكنه الخميس. ننشره الأحد».

An unwritten rule: don't ship before the weekend, or the team spends it fixing things. In the Gulf it's said about Thursday.

Example "The fix is ready, but it's Thursday. We deploy Sunday."

التجربة على أنفسنا(عامية)

Dogfooding · Eat your own dog food(slang)

أن تستعمل الشركة منتجها بنفسها قبل بيعه، فتجد عيوبه قبل عملائها. واشتهرت العبارة في مايكروسوفت منذ مذكّرة داخلية سنة 1988.

مثال موظفو شركة البريد الإلكتروني يستعملون نسختها التجريبية أسابيع قبل العملاء.

A company using its own product before selling it. Popularized at Microsoft by an internal memo in 1988.

Example Staff at an email company use the beta for weeks before customers.

الثمار الدانية(عامية)

Low-hanging fruit(slang)

تحسينات سهلة سريعة بأثر واضح، تبدأ بها قبل الصعب.

مثال «تصغير الصور ثمرة دانية: ساعة عمل وتصير الصفحة أسرع بثانيتين».

Easy, quick wins with clear impact, done before the hard stuff.

Example "Compressing images is low-hanging fruit: an hour of work, two seconds faster."

الطاقة المتاحة(عامية)

Bandwidth(slang)

في كلام الإدارة: الوقت والطاقة المتاحة عند شخص أو فريق، وليس سرعة الإنترنت.

مثال «ليس عندي bandwidth هذا الأسبوع، أعطِها لغيري».

In office talk, available time and energy, not internet speed.

Example "I have no bandwidth this week; give it to someone else."

برمجة الكاوبوي(عامية)

Cowboy coding(slang)

أن يعدّل المطوّر في الإنتاج مباشرة، بلا فرع ولا مراجعة ولا اختبار، معتمدًا على شجاعته وحدها.

مثال تعديل ملف على الخادم الحيّ مباشرة ليلة الإطلاق.

Changing production directly with no branch, review or tests, relying on nerve alone.

Example Editing a file straight on the live server on launch night.

المهندس العشري(عامية)

مثال إعلان وظيفة يطلب «مهندسًا عشريًا» فيُفهم منه ضغط عمل كبير.

A developer said to do the work of ten; a debated idea, since good teams outweigh single stars.

Example A job ad asking for a "10x engineer" often signals heavy pressure.

فحص المعقولية(عامية)

Sanity check(slang)

فحص سريع بديهي أن النتيجة معقولة قبل التعمّق، وليس اختبارًا كاملًا.

مثال تقرير يقول إن المبيعات تضاعفت عشر مرات في يوم: افحص المعقولية قبل الاحتفال.

A quick common-sense check that a result is plausible before digging deeper.

Example A report says sales grew tenfold in a day: sanity-check before celebrating.

الأرض البكر والأرض المبنية(عامية)

Greenfield · Brownfield(slang)

مشروع الأرض البكر يبدأ من الصفر بلا قيود قديمة، ومشروع الأرض المبنية يعمل فوق نظام قائم وكوده الموروث.

مثال بناء تطبيق جديد أرض بكر، وإضافة ميزة إلى نظام عمره عشر سنوات أرض مبنية.

Greenfield starts from scratch with no legacy; brownfield builds on an existing system.

Example A new app is greenfield; adding to a ten-year-old system is brownfield.
